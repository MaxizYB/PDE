# 历史教训、近期讨论与用户要求

这是根据本次对话及保留文档整理的摘要，**不是完整聊天导出**。没有给早期对话编造日期。原始方法与结果保留原目录；并非所有历史实验都在本仓库。

## 1. 演变主线

| 阶段 | 获得的经验 | 应继承的判断 |
| --- | --- | --- |
| MetaPort 局部 Schur、V3.5/V3.9 等 | 数值骨架可保证高精度，但组装、凝聚、接口求解占时；局部预测未自动省掉主求解循环 | 只压缩网络时间不够，须看整次求解和真正替代的工作 |
| 多个纯神经替代/统一框架原型 | 某些快却不准；加组件、反馈和门控不自然产生表达能力 | 不堆模块，模型任务应可解释、可训练 |
| NO+NP 与残差纠偏 | 残差下降不一定降低标签场误差；粗网格算子和细网格标签可能系统失配 | 先统一离散目标，不用新损失掩盖错误方程 |
| CDMC v1/v1.1 | NO 误差匹配训练、多级图设置和物理传播有真实收益；规则/不规则及稳态/时域积累了经验 | 继承机制证据，不把旧数字直接归给新代码 |
| CDMC v2 | 统一离散适配与图层级；矩阵自由执行、稀疏映射、计划优化；大网格训练/测试需对齐 | 几何计划与每材料工作分开，缓存不等于新网格即时成本 |
| 局部物理结构等选题探索 | 场误差会掩盖局部物理误差，但人为构造的响应可能被简单校准解决 | 不能为方法量身造问题，也不能把容易的任务包装成难题 |
| 旧门控与 MG 审计 | 大部分收益来自数值 MG，固定标量门控可能与学习空间门控相当 | NO 剩余分布是观察，必须证明超出强数值和简单门控的收益 |
| 联合空间与去递归 MG | 新方向可补充门控不能表示的误差，少量模式又不能完全替代局部滤波 | 空间表达和平滑不同，不能只看场误差 |
| 128 维非线性字典 | 去除手工区域帽函数；跨材料和多基底有进展，空间相关/正则产生新误差 | 通道数不等于秩，须查 Gram 和空间外方向 |
| HINTS、TB | HINTS 对比有收益，TB 则强于原 CDMC 空间 | 不挑弱基线，匹配空间对照不等于完整 TB-Krylov |
| 有界等维适应 | 平滑材料更准，粗糙近乎持平，动态成本未抵消 | 新空间可能丢失原方向，这是保留参考空间原型的依据，不是已成功的结论 |

早期方法全部代码未纳入，避免重新启动放弃的大分支。V1 文件是定位/机制参考；V2 代码是当前实际依赖。

## 2. 近期用户要求

- 聚焦多尺度椭圆问题，不盲目追求所有 PDE，也不再横向铺满 NS/Maxwell/工业任务。
- 方法应对这一类问题自然成立，不为某个材料图样手工设置很多区域、模式或条件。
- 不能只包装故事；需要在根本设计和实验上超过强 TB，尚未超过就深入识别原因。
- 至少测试另一同类 PDE，例如 Poisson/反应扩散；变化输入必须真正进入模型和方程。
- 同时报告场、梯度、通量、能量、残差、逐样本分布与成本；总体场误差不代替物理结构准确性。
- 可以数值、神经或混合，创新来自独立洞见，不来自组件名称和简单拼接。
- 快速迭代每配置先做一次，最终准出才多 seed；计时重复不等于重复训练。
- 控制上下文：每轮只读当前关键资料，抓住最重要的未知，不反复加载无关历史。
- 写作清楚解释背景、问题、机制、方法、证据；不写成问答堆砌，不防御式写作，也不隐去失败。
- 文档公式用美元符号包裹；直接聊天公式用显示数学括号。
- 本次交接尽量保留原文和代码，不改原项目；服务器 IP/密码脱敏。同一服务器资产只说明路径即可。

## 3. 不重复的具体错误

1. **混版本：** 结果关联代码、检查点、数据与配置，旧图、新方法和不同计时不能混在一起。
2. **对错方程收敛：** 残差趋零而场不准，先查离散目标是否一致。
3. **全部归咎高频：** Fourier 频率不总等于材料相关慢模态，须分析界面和当前能量结构。
4. **用步长补空间：** 门控无法生成空间外方向；可逆坐标变换不改变张成空间。
5. **通道数当秩：** 窄层线性读出受秩限制；非线性读出仍需实测独立性。
6. **正则掩盖病态：** 固定 ridge 会压制弱坐标方向，须分离实现损失和表达不足。
7. **减计算但不重配任务：** 改滤波阶数或频带需训练/测试一致，不能部署旧权重后归咎理论。
8. **漏掉便宜强对照：** 标量、解析空间、POD、成熟 AMG、直接 LU 都应在合适规模下比较。
9. **神经参与即创新：** 初值、残差求逆、投影、学习延拓均有前作，须有新的对象/机制和区分实验。
10. **只报热路径：** 在线含 NO、组装、空间设置/分解和全部更新；网格/预训练/复用成本另列。
11. **算更多当结构胜出：** 维数、滤波、预训练继承、额外训练都须交代。
12. **编译成功当 GPU 成功：** CUDA 稀疏、混合精度、反向传播和模型效果需要实测。

## 4. 接手建议

先读 CURRENT_HANDOFF.md 的三版本划分。复测一致后，可围绕“保留强参考空间，再学习少量真正必要的材料相关缺陷方向”开展小型区分性实验。

这不是用户已确认的新最终主线，而是最新原型的动机。若解析/POD更强、空间成本过高、粗糙材料无泛化收益，就据机制重新判断；不要自动加网络、加投影次数或换容易例子。

不必重读完整历史；遇到对应问题再读 V1、V2 或 MG 审计。相关文献和链接已在论文、论证骨架、方法、基线说明中保留，本交接不新增未核查文献主张。
