# CDMC-PDE 的创新点、论文定位与边界

状态：2026-09-21。本文记录 v1 的方法定位、已有 insight 和严格边界。

类别声明：CDMC-PDE v1 的主身份是 fixed-budget post-solver。神经预条件器是相邻研究方向，也是稳态线性模块可扩展的 solver mode；它不是当前主方法类别。

## 1. 论文核心观点

神经算子、固定预算后校正和 tolerance-driven 数值求解构成同一离散问题的不同计算深度。CDMC-PDE 占据中间的 fixed-budget post-solver 工作点：NO 负责一次性消除容易预测的主要解结构，稳定数值骨架消除其擅长的误差，学习模块只作用于两者留下的互补缺陷。

这不是简单地把 NO 输出当作传统求解器初值，也不是在 NO 后接一个黑盒误差网络。方法要求组合对象、闭合对齐、训练分布和固定求解深度同时成立。

## 2. 候选核心创新

### 创新一：NO 条件的互补缺陷，而不是通用近似逆

稳态线性情形具有精确恒等式

\[
I-A\left[B_N+B_C(I-AB_N)\right]
=\left(I-AB_C\right)\left(I-AB_N\right).
\]

因此模型学习的是 \(\operatorname{range}(I-AB_N)\) 上的校正作用。它把训练对象从“逼近完整逆”缩小为“消除特定 NO 稳定留下的误差子空间”。

### 创新二：显式区分求解误差与离散闭合误差

当公开数据由细网格、细时间步或不同离散生成时，真值并不一定满足部署方程。CDMC-PDE 在进入预条件或缺陷迭代前，先学习

\[
c_\phi\approx\mathcal D_c(Z^*),
\]

再求解 \(\mathcal D_c-c_\phi=0\)。这避免神经/数值混合方法认真收敛到错误离散方程。

### 创新三：同一范式下的稳态空间多层与时域时间块求解

稳态使用空间图多层互补校正；时域使用闭合对齐的 multiple shooting 和因果/多层时间传播。两者共享

\[
\text{NO proposal}
\rightarrow\text{aligned defect}
\rightarrow\text{fixed complementary solve},
\]

而不是为每个 PDE 名称拼装独立网络。

### 创新四：部署一致的闭合训练

时间闭合不是只在真值父节点上回归，而是在模型自己的预测父节点分布上训练。当前 NS 实验已经证明，该修改能把统一 10 帧 mean 从 6.6554% 降至 6.3923%。

### 创新五：一次 setup 与固定计算谱

网络在一次算子或时间块 setup 中生成路由或闭合，后续执行固定稀疏数值作用。\(K=0,1,2\) 或完整扫描形成可审计的速度--精度谱，不使用按样本回退掩盖不稳定性。

## 3. 与相关方向的区别

### 与纯神经算子

纯 NO 学习 \(\xi\mapsto Z\)，速度快但长程、高频、OOD 或约束误差可能积累。CDMC-PDE 保留 NO 作为快速端点，同时显式读取真实缺陷并利用数值结构修正。

### 与神经预条件器

常规 NP 主要根据算子学习通用预条件作用，并在 Krylov 中反复调用。CDMC-PDE 的 setup 同时条件化于算子和当前 NO 缺陷，目标是 NO 的互补误差，并优先使用固定浅层校正而不是大量外层迭代。

### 与 learned multigrid

CDMC-PDE 不以“神经化 MG 参数”作为创新本身。Darcy 消融已经表明，在简单规则网格上随意学习传递算子收益很小。学习只在它能够改变 NO 互补误差的粗空间、路由或闭合时保留。

### 与 residual/error corrector

一般残差校正通常从预测场计算残差，再输出误差。CDMC-PDE 额外要求：

1. 先审计真值是否为部署离散方程的根；
2. 必要时显式学习离散闭合；
3. 修正通过固定数值骨架产生；
4. 稳态与时域共享同一互补缺陷分解；
5. 训练必须覆盖实际部署状态分布。

### 与“NO 作为数值初值”

只把 NO 作为 Newton/Krylov 初值不能构成本文方法。CDMC-PDE 的学习 setup 读取 NO 缺陷，并主动改变有限计算预算中的误差消除顺序；时域闭合还由 NO 轨迹条件化。

## 4. 不能作为创新声明的内容

以下内容已有大量相关思想，不能单独声称首创：

- 使用 NO 作为初值；
- 使用残差修正预测；
- 学习预条件器；
- 神经化多重网格；
- Newton、Krylov、SDC、MGRIT 本身；
- 图网络处理非结构网格；
- 用固定次数迭代形成速度--精度点。

论文新颖性应落在“NO 互补缺陷 + 离散闭合对齐 + 稳态/时域统一实例 + 部署一致训练”的整体结构及其实证规律。

## 5. 当前能够声称的结果

1. Darcy 上，NO 缺陷条件化的 CDMC-DR M2 优于 coefficient-only learned setup，并形成 FNO 与高精度 MG 之间的固定 Pareto 点。
2. NS 上，闭合对齐和完整因果传播解决了错误宏残差与传播范围不足问题，完整 10 帧 mean 达到 6.3923%，优于 FNO、旧 NODC 和纯 Oseen。
3. 两个任务均支持“只学习互补缺陷比重新预测完整场更有效”的研究假设。
4. 稳态和时域可以通过同一离散缺陷接口表达，但一般性仍需更多 PDE 和网格验证。

## 6. 当前不能声称的内容

- 已经全面超过成熟数值求解器；
- 已经实现任意 PDE、任意几何、任意网格；
- 当前 NS 方法同时支配 FNO 的速度和精度；
- 当前 Darcy learned setup 在简单规则网格上比所有 MG 更快；
- 一个统一 checkpoint 可以跨 PDE 使用；
- 已达到标准 benchmark SOTA。
