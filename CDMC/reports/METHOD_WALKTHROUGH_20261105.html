0　先记住五个对象和一条恒等式

符号含义规模
A刚度矩阵，由当前材料 a 装配N×N，N = 65,025（257² 网格）
b载荷向量（源项与边界提升）N
x*参考解（离散方程的真解）N
x当前近似解（神经算子预测，或某轮校正后的解）N
r = b − Ax残差：当前解在方程上的“亏损”N

离散方程是

A x* = b

由此立刻得到整篇文章的出发点：

A(x* − x) = b − Ax　⟹　A e = r，　e := x* − x

这条恒等式说的是：残差不是误差的“代理指标”，它就是误差经过 A 变换后的结果。想得到误差，就要解一个和原问题同规模的方程 Ae = r，这等于把原问题再解一遍。方法的所有设计，都是为了不解这个方程，又能把 e 近似出来。

一句话：残差是误差的另一种写法；方法的目标是用很小的代价把 e 从 r 里“反推”出来。

1　从 PDE 到线性系统：A 和 b 是怎么来的

原方程

−∇·(a∇u) = f　in Ω，　u = g　on ∂Ω

两边乘测试函数 v（边界上为 0），分部积分：

∫Ω a ∇u·∇v dξ = ∫Ω f v dξ

把边界条件写成 u = ug + w，w 在边界为 0，得到弱形式：

∫Ω a ∇w·∇v dξ = ∫Ω f v dξ − ∫Ω a ∇ug·∇v dξ

在三角网格上用 P1 基函数 φi，令 wh = Σi xiφi，逐个用 φj 测试：

Aij = ∫Ω a ∇φi·∇φj dξ，　　bj = ∫Ω f φj dξ − ∫Ω a ∇ug·∇φj dξ

符号在做什么：

  • Aij：基函数 i 与 j 之间的“能量耦合”，只由材料 a 和网格几何决定；
  • bj：源项在第 j 个基函数上的投影，减去边界提升的贡献；
  • 正系数 a > 0 保证 A = AT 正定，这是后面所有能量论证的前提。

实际装配不需要做积分：P1 基函数在三角形上是线性的，梯度为常量，单元刚度矩阵有闭式

ATij = |T| aT ∇φi|T · ∇φj|T

其中 aT 是三个节点材料值的平均。网格几何与稀疏结构预先生成一次，换材料时只重算 aT 与这些数。

一句话：A 是材料在离散层面的全部信息；换材料就是换 A，其他都不变。

2　为什么不能直接解 Ae = r

能解，但代价和原问题一样：一次完整的细网格求解。方法要面对的是“材料反复变化”的场景，如果每份材料都解一次细网格方程，就没有节省可言。

所以策略是：把误差限制在一个低维子空间里近似，

e ≈ Z c，　Z 为 N×r，r = 128 ≪ N

Z 的每一列是一个“修正方向”，c 是 r 维系数。问题拆成三件事：

  1. Z 从哪里来？由网络根据材料、当前解和残差生成（学习部分，只做一次）。
  2. c 怎么定？由当前离散方程解一个 128×128 的小系统（物理部分，每轮都做）。
  3. 怎么让它便宜？先滤波把“容易消”的误差消掉，让 Z 只处理“难消”的部分；Z 与小系统分解在轮次间复用。
一句话：网络只负责“往哪些方向修”，方程负责“每个方向修多少”。

3　第一步：滤波，先把“振荡型”误差压掉

3.1　误差的“粗糙程度”怎么度量

考虑广义特征问题

A v = λ D v，　D = diag(A)
  • λ 小：特征向量在 A-内积下“平滑”，对应大范围、缓变的误差；
  • λ 大：特征向量“振荡”，对应细尺度、高频的误差；
  • λ 的最大值记为 λU。

为什么用 D−1A 而不是 A？因为 D−1A 与对称正定的 D−1/2A D−1/2 相似，特征值全为正实数，且量级被对角缩放控制在 O(1)。若不做这个缩放，λmax 会随材料和对比度剧烈变化，滤波参数无法固定。

λU 不通过特征分解求，而用 Gershgorin 行界估计：

λU = (1 + 10−6) · maxi ( Σj |Aij| / Aii )

读法：第 i 行所有元素绝对值之和除以对角元，是 D−1A 第 i 行元素的绝对值之和；矩阵任一特征值都不超过这个行和的最大值。直角三角网格上它约等于 2；10−6 只是防止浮点求和误差越界。

关键：滤波的所有参数都由当前矩阵算出来，不依赖“这是什么 PDE、什么材料”。

3.2　Chebyshev 多项式在做什么

滤波不是“解方程”，而是对当前解做固定步数的迭代。设 Sm 表示 m 步 Chebyshev 半迭代，误差传播为

ē = pm(D−1A) e，　　pm(λ) = Tm((d − λ)/c) / Tm(d/c)

其中 Tm 是 m 次 Chebyshev 多项式，

d = (λU + λc)/2，　c = (λU − λc)/2，　λc 为截止值

多项式的形状（理解滤波的关键）：

  • λ = 0 时 pm(0) = 1：最平滑的分量不被衰减；
  • λ 落在 [λc, λU] 时，|pm(λ)| ≤ 1/Tm(d/c)：这一段被压到很小，并在正负之间等幅振荡；
  • 因此它是一个高通抑制器：保留接近零的谱分量，压掉其余分量。

它还有性质：在整个谱区间上 |pm(λ)| ≤ 1，于是

‖ē‖A = ‖pm(D−1A) e‖A ≤ ‖e‖A

滤波在精确算术下不会让能量误差变大，这是它可以放在流程最前面、又不破坏后面校准单调性的原因。

3.3　递推公式怎么读

ρj = (2d/c − ρj−1)−1
δj = (2ρj/c) D−1(b − A xj) + ρjρj−1δj−1
xj+1 = xj + δj
  • b − A xj：当前残差，每次迭代算一次；
  • D−1(b − A xj)：对残差做对角缩放（Jacobi 预条件），让更新量量级正常；
  • ρj：Chebyshev 递推系数，只依赖 λU、λc 和步数，不依赖当前解；
  • δj：第 j 步的更新方向，带上一步的记忆；
  • xj+1 = xj + δj：更新解。

成本：每一步只需一次稀疏矩阵乘 A xj 和一次对角缩放，O(s)，s 为非零元个数。64 步就是 64 次稀疏矩阵乘，没有分解、没有全局通信。

3.4　参数与效果

阶段步数截止值作用
预滤波640.0005 λU压掉高频振荡，改变剩余误差的分布
后滤波80.025 λU清理投影后引入的局部粗糙分量

实测（8 份验证材料）：导数误差 45.38% → 4.36%，通量误差 77.56% → 5.24%；状态误差只从 1.54% 降到约 1%。这说明：

  • 导数和通量误差主要由高频分量贡献，滤波对它们最有效；
  • 状态误差主要由低频分量贡献，滤波几乎动不了它；剩下的“平滑但整体错”的误差，才是学习的对象。
一句话：滤波负责“能便宜消掉的”，它消不掉的那部分，交给低维响应空间。

4　第二步：响应字典，网络生成 128 个修正方向

4.1　输入：7 个通道

通道含义为什么需要
log ai / log 12材料系数的对数（固定尺度 12 归一化）把跨 104 的对比度压到 O(1)
相对中位数的对角对数log Dii − median(log D)局部材料刚度
两个坐标节点位置边界与几何位置
相对中位数的节点质量对数局部网格尺度网格疏密
x̄i / RMS(x̄)滤波后的状态当前解的形状
(D−1r)i / RMS(D−1r)滤波后的残差还差在哪里

前四个描述“材料与几何”，后两个描述“当前任务”。没有后两个，网络只能生成通用方向；有了它们，才能针对当前样本的剩余误差生成方向。

4.2　多层图：为什么要“多尺度”

残差的结构跨尺度：有的分量在一个大区域内整体偏，有的只在材料界面附近偏。单一尺度的消息传递感受野有限。

  1. 用聚合把细网格逐层粗化，得到 prolongation 矩阵 Pℓ（粗→细）；
  2. 限制算子取 Rℓ+：把 |Pℓ|T 按行归一化，即正权平均，避免正负抵消；
  3. 每层的邻接 𝒢ℓ 取“单位材料参考矩阵”的非对角绝对值并按行归一化；材料变化时复用，不重建图。

消息传递块：

ℬℓ(H) = H + GELU[ LN( H Ws + 𝒢ℓ H Wn + bs ) ]
  • H Ws：节点自身特征的线性变换；
  • 𝒢ℓ H Wn：邻居特征的加权平均（图上的扩散）；
  • 两者相加，LayerNorm 归一化，GELU 加非线性；
  • 外面的 H + …：残差连接，保留原特征，训练更稳。

下行（细→粗）扩大感受野：

H1 = ℬ1↓(O1)，　Hℓ = ℬℓ↓(Oℓ + Rℓ−1+Hℓ−1)

读法：第 ℓ 层的特征 = 本层输入 Oℓ + 更粗层特征的平均池化 R+H，再过消息块。越往下，一个节点“看到”的范围越大。

上行（粗→细）把全局上下文带回细节：

Uℓ = ℬℓ↑[ GELU( [Hℓ, PℓUℓ+1] Wmerge + bmerge ) ]

读法：把本层特征 Hℓ 与粗层上采样 PℓUℓ+1 拼在一起，线性融合后再过消息块。下行所有层共用一套 (Ws, Wn)，上行共用另一套，所以参数量不随层数增长。

4.3　输出与“秩”的问题

Z̃ = tanh[ P0( U1 Wout + 1 boutT ) ]

为什么必须是非线性读出？如果最后一步是线性的，即 Z̃ = H W + 1 bT，那么 rank(Z̃) ≤ w + 1。隐藏宽度 w = 16 时，即使输出 128 个通道，这 128 列最多张成 17 维空间，多出来的通道是冗余的。加逐元素 tanh 后，每一列是隐藏特征的不同非线性函数，可以彼此独立。实测奇异值谱：线性读出在第 18 个方向断崖（秩 17），非线性读出铺满 128 维。

网络总共 3,952 个参数，与网格规模无关。

4.4　整形与归一化

得到 Z̃ 后，先做两次阻尼 Jacobi 平滑：

Z̃j+1 = Z̃j − (4/(3λU)) D−1A Z̃j，　j = 0, 1

读法：把每个方向的高频毛刺磨掉。λU ≈ 2 时系数 4/(3λU) ≈ 2/3，正是经典阻尼 Jacobi 的权重。然后每列按 √(zjTA zj) 归一化，使每个方向的 A-能量为 1；各列量级一致，Gram 矩阵不会因为某列特别大而病态。

一句话：网络输出的是 128 个“磨平、归一化”的形状，不是解本身。

5　第三步：校准，方程决定每个方向修多少

5.1　从“最小能量”出发

离散问题的能量泛函是

ℰ(x) = ½ xTA x − bTx

它的梯度是 A x − b = −r，驻点就是 A x = b。现在限制修正只能发生在 Z 张成的空间里，即 x + Z y，并加一个很小的正则项：

c = argminy [ ℰ(x + Z y) + (η/2)‖y‖22 ]，　η = 10−5

对 y 求导令其为零：

ZTA(x + Z c) − ZTb + η c = 0　⟹　(ZTA Z + η I) c = ZT(b − A x)

记

G = ZTA Z，　H = G + η I，　q = ZTr

就得到方法文档里的三行：

G = ZTA Z，　H = G + η I，　H c = ZT(b − A x)，　x+ = x + Z c

5.2　每个符号在做什么

  • G：128×128 的 Gram 矩阵，元素 Gij = ziTA zj，描述两个方向在能量内积下的耦合；
  • q = ZTr：把 N 维残差投影到 128 个方向上，得到“每个方向上还差多少”；
  • H = G + ηI：加正则，保证方向接近线性相关时也能稳定求解；
  • c：每个方向的幅度；
  • x+ = x + Zc：用这 128 个方向组合出修正。

关键：网络只提供 Z，G 和 q 都由当前 A、b、x 算出。材料对比度变化时，幅度会自动按物理量级缩放；网络不需要学习“物理单位”。

5.3　几何解释：在子空间上做投影

把误差 e 看成一个 N 维向量，Z 的 128 列张成一个子空间。校准做的事，是把 e 投影到这个子空间上，只不过“垂直”是在 A-内积

⟨u, v⟩A = uTA v

下定义的。η → 0 时，

Z c = Z (ZTA Z)−1 ZTA e = ΠA e

ΠA 是 A-正交投影算子。投影残差 e − Z c 与子空间 A-正交，所以它是子空间内能量意义下最优的修正。

用一个一维例子把“方向 vs 幅度”说透。假设 Z 只有一列 z，最小化 ½‖e − c z‖²（A-范数）得

c = (zTA e) / (zTA z) = (zTr) / (zTA z)

如果把 z 放大 10 倍，分子分母同时放大 100 倍，c 缩小 10 倍，c z 不变。所以网络即使把方向的尺度搞错，也不影响结果；它只需要把“形状”学对。这就是“方向由网络、幅度由方程”的精确含义。

5.4　能量不增的证明

记 e = x* − x。由 H c = q = ZTA e，有

‖e − Zc‖A2
= ‖e‖A2 − 2 cTZTA e + cTG c
= ‖e‖A2 − 2 cTH c + cTG c
= ‖e‖A2 − cTG c − 2η‖c‖22

因为 G 半正定、η > 0，右边一定不超过 ‖e‖A2。每一步校准都不会让能量误差变大；η = 0 时正好是投影，误差严格不增。

一句话：校准是一个带正则的 Galerkin 投影；它把“往哪修”交给网络，把“修多少”交给方程。

6　第四步：去偏，为什么多解一次小系统还能再好一点

正则项 η 让 H 稳定，但也让系数“缩水”了一点：真正的投影应该用 G−1q，实际用的是 (G + ηI)−1q。两者差多少？利用恒等式

G−1 = (I + ηG−1)−1 H−1 = H−1 − ηH−2 + η2H−3 − ⋯

可以把“无正则解”写成无穷级数。方法只取前 t 项：

d0 = H−1q，　dj+1 = H−1(η dj)，　ct = Σj=0t−1 dj

读法：d0 就是原来的校准；d1 是用同一个 Cholesky 分解再解一次得到的修正项；c2 = d0 + d1 就是两次小求解。每多一项只多一次三角回代，O(r2)，不增加任何 A 的作用。

对 G 的特征值 λ，这个截断相对“理想投影”的增益是

gt(λ) = λ Σj=0t−1 ηj / (λ + η)j+1 = 1 − (η/(λ + η))t ∈ [0, 1]
  • λ ≫ η 时，η/(λ + η) ≈ 0，g1 ≈ 1：大特征值方向本来就没被正则影响，多解无益；
  • λ ~ η 时，η/(λ + η) ≈ 1/2，t = 2 把偏差从 1/2 降到 1/4；
  • 所以去偏只对小特征值方向有效，这正是正则影响最大的地方。

实测：平滑 0.00415 → 0.00336，粗糙 0.00949 → 0.00787，六尺度 0.01383 → 0.01299；七个组合、16/16 样本全部改善，代价约 0.1–0.2 ms。

一句话：去偏是把正则带来的“缩水”用小系统自身的级数补回来，不动大网格。

7　第五步：多轮与复用，为什么网络只调用一次

一轮的完整操作是：

  1. 预滤波 Spre；
  2. 用当前残差做校准 x ← x + Zc；
  3. 后滤波 Spost。

固定 Z、忽略 η 时，一轮的误差传播可以写成

e(k+1) = Spost (I − ΠA) Spre e(k)
  • Spre 压掉高频分量（子空间不擅长表示的部分）；
  • I − ΠA 是投影后的残差，去掉子空间能覆盖的部分；
  • Spost 再清理投影可能引入的局部粗糙分量。

三者复合是收缩算子，所以轮数越多误差越小。实测：K1 约 10−1%，K2 约 10−2%，K4 约 10−3%。

为什么 Z 不每轮重算？因为 Z 由材料、初始状态和初始残差生成，后续轮次只改变 x，材料不变；实验显示复用同一 Z 到 K4 仍然收敛。复用带来两个好处：网络只调用一次（3.22 ms），Gram 与 Cholesky 只做一次（3.50 ms）；每轮只剩预滤波（4.26 ms）、小系统回代和后滤波。

一句话：“一次设置、多轮使用”是成本优势的来源，也是与逐轮调用网络的混合方法的主要区别。

8　训练：为什么用对数损失、为什么展开四轮

训练时冻结神经算子，用它的真实预测经过预滤波后的状态作为输入。展开 K = 4 轮，损失是

ℒ(θ) = (1/(3K)) Σk=1K Σj∈{u,g,q} log max( Ej(k), 10−6 )
  • Ej(k)：第 k 轮、第 j 个输出（状态/导数/通量）的相对误差；
  • 对 k 求和：让网络对每一轮之后的误差都负责，而不是只管第一轮；
  • 对 j 求和：三项物理输出同等重要，避免只优化状态；
  • log：不同轮次误差差几个数量级（K1 约 10−1，K4 约 10−3），直接平均会被第一轮主导；取对数后各轮贡献均衡，后期小误差也能持续参与优化；
  • max(·, 10−6)：防止 log 0，只影响数值安全。

梯度通过“空间生成 → 整形 → Gram → Cholesky → 更新”整条链路反传（BPTT）。验证集用同一目标选模。

一句话：训练目标不是“预测得准”，而是“四轮校正之后三项物理输出都准”。

9　为什么有效、什么时候失效：覆盖率

把误差做能量变换：y = A1/2e，Q = A1/2Z。投影后残差的能量是

‖(I − ΠQ) y‖22，　ΠQ = Q (QTQ)† QT

如果误差来自某个分布，协方差 C = E[y yT]，那么期望残差能量是

E‖(I − ΠQ) y‖22 = tr[ (I − ΠQ) C ]

读法：Z 好不好，不取决于它“看起来像不像解”，而取决于 C 的能量有多少落在 Q 张成的子空间里。这就是“任务覆盖”。

  • 固定正弦空间对“最慢 16 个模态”的覆盖是 67.43%，但对实际误差分布只有 8.56%；
  • 学习空间对慢模态的覆盖是 67.12%（几乎一样），但对实际误差是 77.70%。

所以“更好的通用低频基”不是答案；必须让空间依赖当前材料与残差。

失效条件：对比度从 6 外推到 60 时，相结构没变，但材料耦合强度变了，覆盖率从 79.06% 降到 57.15%，状态误差从 10−4 量级升到 1.69%（K2）。增加小求解次数只把覆盖率提到 59.34%，说明缺口在空间覆盖，不在幅度或求解精度。

三个物理误差为什么能被能量控制住：正系数给出

α‖∇e‖L22 ≤ ‖e‖a2 ≤ β‖∇e‖L22，　α‖e‖a2 ≤ ‖a∇e‖L22 ≤ β‖e‖a2

再由 Poincaré 不等式 ‖e‖L2 ≤ CP‖e‖a/√α。所以能量误差小，三个物理误差都小；但常数依赖对比度 β/α，高对比时能量误差可能掩盖更大的通量误差，这就是三项必须分别评价的原因。

12　几个常见的“看不懂”点，直接回答

Q1　为什么不直接解 Ae = r，而要学一个 Z？
因为解 Ae = r 就是再做一次完整求解，材料反复变化时成本没有下降。Z 把“求解”换成了“在 128 维里选系数”，小系统 128×128 的代价可以忽略。

Q2　为什么用 D−1A，不直接用 A？
D−1A 与对称正定矩阵相似，特征值为正、量级被对角缩放控制在 O(1)，λU ≈ 2，滤波参数才能固定且与材料无关。用 A 的话，谱宽随对比度变化，多项式参数需要逐材料调。

Q3　η 能不能去掉？
能去掉，当 Z 的列线性无关且数值条件好时，η = 0 就是纯投影。保留 η = 10−5 是为了在列接近相关时 Cholesky 稳定；代价是很小的幅值偏差，用第 6 节的去偏补回来。

Q4　为什么网络只调用一次，后面不重新生成 Z？
Z 的条件是材料、初始状态和初始残差；材料不变时，后续轮次只是 x 变了，方向空间仍然适用。实验上 K4 仍收敛；复用省掉了每轮的图网络与分解。

Q5　为什么不用 PCG？
固定轮次、无停止准则，是为了计时可比、空间与分解可复用。PCG 每轮需要新的 Krylov 空间，收敛速度又依赖材料条件数，会把“表示能力”和“迭代次数”混在一起。

Q6　128 维是怎么定的？
64 和 128 是两个容量工作点。128 维在秩诊断中已满秩，K2 到 10−2%、K4 到 10−3%；再增大维度，Gram 的 O(Nr2) 与存储 O(Nr) 上升，收益递减。

Q7　为什么训练用 log，不用均方误差？
四轮展开后误差跨几个数量级，均方误差会被第一轮的大误差主导，后期 10−3 的改善几乎不产生梯度；对数把各轮拉到同一尺度，后期小误差持续参与优化。

Q8　这个方法什么时候会失效？
当测试材料的剩余误差方向超出 Z 的覆盖时。对比度外推实验就是例子：覆盖率 79% → 57%，误差上升两个数量级；此时增加小求解次数或调幅都无效，需要把材料连接强度纳入方向生成。
