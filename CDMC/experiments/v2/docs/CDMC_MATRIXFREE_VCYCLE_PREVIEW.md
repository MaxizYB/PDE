# CDMC v2：矩阵无关多级执行预览

本页记录 2026-09-28 对**现有 CDMC 主线的早期矩阵无关执行预览**，其中累计投影及精确粗层映射属于历史阶段。之后的可扩展计划已接入正式 evaluate-compiled 命令；当前方法与复测数字以[阶段整理](CURRENT_STAGE.md)为准。Geo-FNO 权重、缺陷条件化图网络权重、固定两轮 V-cycle、层间传递与末端能量更新均沿用原版；不重新训练模型。实验仍是项目生成的 Darcy P1-FEM pilot，不是一般 PDE 或工业网格结论。

## 方法：保留多级校正，改变在线算子的表示

固定网格时，网格层级和传递 $P_\ell,R_\ell$ 只建立一次。令 $Q_0=I$、$Q_{\ell+1}=Q_\ell P_\ell$。对每个新系数样本 $a$，细层仍使用**精确 P1 单元作用**，中间层的 Galerkin 作用通过

$$
A_\ell(a)v=Q_\ell^\top A_0(a)Q_\ell v
$$

执行，不在线生成这些层的完整稀疏矩阵。为保留原来两轮校正所需的信息，按单元预编译并在线求值的仅有中间层对角线，以及最底层的小矩阵：

$$
D_\ell(a)=\operatorname{diag}\!\left(\sum_T a_TQ_\ell^\top K_T^{(0)}Q_\ell\right),\qquad
A_L(a)=\sum_T a_TQ_L^\top K_T^{(0)}Q_L.
$$

这里 $K_T^{(0)}$ 是单位系数的局部刚度模板，$a_T$ 为当前样本的单元系数。预编译只保存中间层的“系数到对角线”映射和最底层的“系数到小矩阵”映射；不保存每一级的完整系数到矩阵映射。真实右端、细层对角线和 NO 缺陷由当前样本的矩阵无关 P1 作用计算。现有图网络仍根据该缺陷产生平滑与粗层门控，然后进行两轮原结构 V-cycle。

最底层不再逐样本显式求逆。对**当前样本的精确** $A_L(a)$ 做固定 2 步 PCG，预条件子是每网格只求一次的参考粗矩阵逆。这不是用参考矩阵代替当前方程：每一步的矩阵作用仍取自 $A_L(a)$。参考网格的 Jacobi 阻尼在本次三几何测试中沿用为固定值；此改动和底层 2 步校正使最终数值与原版接近，但不宣称逐位相同。在线的系数准备、图网络门控和两轮校正整体捕获为固定形状 CUDA Graph；NO 使用已有的独立推理图。

## 主结果

同一已有 NO/CDMC checkpoint，batch=1，CPU 新样本输入，RTX 4090，规则、不规则及几何 OOD 各 16 个测试样本。误差为质量加权相对场 $L^2$ 百分比；时间为预热后逐样本同步的热态端到端均值。下表旧版时间取现行正式评测；新原型在服务器另一张同型号、较空闲的 GPU 上测得。为了排除评测中其他方法的干扰，还在新 GPU 上独立重跑了旧版，结果列于下一段。

| 数据 | 旧 CDMC K2：误差 % / ms | 新 CDMC K2：误差 % / ms | 同路径固定 MG K2：误差 % / ms | 新 CDMC P95 误差 % |
| --- | ---: | ---: | ---: | ---: |
| 规则 33×33 | 0.01020 / 4.253 | **0.01030 / 1.734** | 0.02062 / 1.736 | 0.01584 |
| 不规则 ID | 0.00899 / 4.229 | **0.00825 / 1.752** | 0.01842 / 1.671 | 0.01473 |
| 几何 OOD | 0.05711 / 4.188 | **0.05151 / 1.779** | 0.16811 / 1.748 | 0.09168 |

在**相同加速路径**下，CDMC 相比关掉神经门控的固定 MG，三组 mean 场误差分别降低约 **50.0%、55.2%、69.4%**；图执行阶段的额外时间约 **0.08–0.09 ms**。这说明神经缺陷分配仍在发挥原来的作用，而不是仅靠矩阵无关化改变了误差。底层改成 1 步时，规则网格误差升至 **0.02169%**，总时间仅从 **1.734 ms** 减到 **1.675 ms**，故保留 2 步。

同 GPU、仅运行旧 CDMC 的隔离计时为规则 **0.01020% / 6.073 ms**、不规则 **0.00899% / 4.450 ms**、OOD **0.05711% / 5.928 ms**。这轮旧路径耗时高于此前正式评测，说明服务器状态和执行顺序会影响跨进程墙钟；不把 6.073 与 1.734 的比值当作稳定加速倍数。按此前正式热态表，新路径约为 **2.4 倍**延迟改善，仍需专门的重复 A/B 确定窄幅差别。逐样本 JSON 保留了所有计时波动。

又在同一进程、同一 GPU、相同 16 个样本上交替运行两条路径，并在计时前分别暖机。下表采用抗偶发抖动的逐样本时间**中位数**；两条路径都包含同一次 NO 推理。

| 数据 | 旧 CDMC，ms | 新 CDMC，ms | 旧/新 |
| --- | ---: | ---: | ---: |
| 规则 33×33 | 5.593 | 1.860 | 3.01× |
| 不规则 ID | 5.856 | 1.814 | 3.23× |
| 几何 OOD | 6.493 | 1.866 | 3.48× |

同进程记录还包括旧版系统构建、门控与校正的分段时间；旧构建阶段有较明显墙钟波动，因此上述中位数和主表中的正式热态均值是两种口径，不能互相拼接计算加速比。该 A/B 只改变执行后端，使用同一套 NO/CDMC 权重。

## 一致性、冷启动和显存

先只替换各层作用、保持旧版对角线/阻尼/粗层逆时，四个规则样本的新旧最终解最大逐点差约 $1.3\times10^{-8}$；这验证了隐式 Galerkin 作用本身。完整新路径又替换了参考阻尼及底层两步校正；三组相同样本相对旧版的最终解最大逐点差依次约 $1.28\times10^{-6}$、$4.59\times10^{-7}$、$3.21\times10^{-6}$，对应误差见主表。底层只用隐式细层作用去做粗层 PCG 时，图执行反而超过 2 ms；在线保留**小的精确终端矩阵**是本轮有效设计的关键。直接把旧系统构建和在线粗层求逆一起捕获会在 GPU 求逆处失败；新路径避免了该在线逆。

| 一次性或空间成本 | 规则 | 不规则 ID | 几何 OOD |
| --- | ---: | ---: | ---: |
| 新网格计划含投影映射，ms/网格 | 1484 | 1430 | 1118 |
| 其中投影映射编译，ms/网格 | 822 | 670 | 530 |
| 新求解图捕获，ms/网格 | 76 | 151 | 65 |
| 新路径 standalone 峰值 PyTorch allocated，MiB | 142.8 | 92.8 | 103.1 |

以上不含进程启动、依赖导入和 NO 权重加载；NO 的首次 CUDA 图准备在原始 JSON 另列。冷启动代价目前比旧版高约一秒，显存也显著增加，原因是每网格投影映射及整段图捕获保留的中间张量。因此热态提速适合**同一网格反复改变系数或右端**，不能直接推广为“每个样本都是新网格”的端到端加速。要跨样本任意拓扑仍需降低层级/投影构建成本并限制图内存；这里尚未验证工业网格规模。

后续[新网格扩展性实测](MESH_PLAN_SCALING_AUDIT.md)表明：本页这版约 1 秒的网格计划仅适用于千节点 pilot；4225 节点的完整计划 90 秒内未完成。稠密跨层基与投影映射编译后来已重构，新的 66,049 节点构建及精度、速度结果见[优化报告](MESH_PLAN_OPTIMIZATION.md)。两版都是实验路径，不能据本页热态表推断大网格推理性能。

本次预编译利用 Darcy P1 局部矩阵对单元系数的线性展开；不同 PDE 可沿用“层级算子作用 + 少量在线统计 + 小终端系统 + 缺陷条件化门控”的接口，但必须由其离散适配器提供相应局部作用及统计，**不能**把这组 Darcy 数字当作一般 PDE 的验证。另外，在当前中等对比 Darcy pilot 上，[固定粗空间纯数值 PCG 预览](MATRIXFREE_COARSE_PREVIEW.md)仍是更快的强基线；本页证明的是**CDMC 自身的多级神经—数值主线能够移除在线全矩阵构建并显著降低热态延迟**，尚未证明它在所有精度—时间点上优于最强纯数值路线。

实现与原始证据在 `experimental/{matrixfree_cdmc_vcycle_probe.py,matrixfree_cdmc_partial_probe.py,matrixfree_cdmc_full_graph_probe.py,cdmc_isolated_reference.py}` 和 `results/performance/matrixfree_20260928/`。结果文件名中的 `compact_*_gpu1` 为主对照，`*_standalone_gpu1` 为不加载参考求解器的内存/时间测量，`full_mg_*` 为相同路径的神经门控消融，`ab_warm_*` 为同进程暖机 A/B。服务器保留训练权重；本地只同步代码和 JSON。

## 复现实验入口

从服务器 `Graph` 工作目录运行以下命令；把 `pilot_regular`、两个 checkpoint 目录同时换成不规则数据与对应权重即可重复不规则 ID/OOD 测试。`--skip-reference` 只跳过旧求解器对照，以便单独计量新方法显存；去掉它则额外记录逐样本新旧解差值。`--corrector mg` 在同一执行路径上关闭神经门控。两轮 V-cycle 目前是固定结构，`--coarse-steps 2` 指最底层的两步 PCG，不是 V-cycle 轮数。

```sh
PY=/home/caohuilin/.conda/envs/gtmsmw/bin/python
CUDA_VISIBLE_DEVICES=1 "$PY" CDMC/experiments/v2/experimental/matrixfree_cdmc_full_graph_probe.py \
  --data baselines/data/darcy_v2/generated/pilot_regular \
  --proposal-dir CDMC/experiments/v2/results/pilot_regular \
  --checkpoint-dir CDMC/experiments/v2/results/final128_regular \
  --count 16 --coarse-steps 2 --corrector cdmc --skip-reference \
  --out CDMC/experiments/v2/results/performance/matrixfree_20260928/reproduce_regular.json
```
