# v2 数值计算量削减：两条结构尝试与 2026-09-28 验证

本页记录结构性实验，不取代 [现行正式结果](EXPERIMENTS.md)。所有实验复用同一批 16 个规则 ID、16 个不规则 ID、16 个凹口几何 OOD 样本及原有 NO/CDMC 权重。单样本热态计时均在同服务器 RTX 4090、CPU 新样本输入；不同进程计时有波动。当前正式默认后端继续使用 `gpu_hybrid`。

## 1. 精确离线—在线多层算子

目前 Darcy P1 单元刚度对单元系数 $\bar a_t$ 线性。固定网格和固定多层传递时，可先在离线阶段把每个单元的局部矩阵投影到各层，构造线性映射 $\mathcal C_\ell$：

$$A_\ell(a)=\mathcal C_\ell(\bar a),\qquad A_{\ell+1}(a)=R_\ell A_\ell(a)P_\ell.$$

在线阶段仍由**当前样本**的系数生成各层矩阵，但不再对每个样本做逐层稀疏/稠密 $RAP$。每层粗矩阵、粗层逆、两轮 V-cycle 和已训练模型都保留；这是网格预编译与计算时机改变，不是参考系数近似。可由 `--system-backend gpu_affine` 选择，`auto` **没有**改为本试验后端。

| 同权重 K=2 | 规则 ID | 不规则 ID | 几何 OOD |
| --- | ---: | ---: | ---: |
| 混合后端在线系统 (ms) | 1.931 | 1.878 | 1.858 |
| 精确预编译在线系统 (ms) | **1.478** | **1.403** | **1.351** |
| 混合后端 CDMC 总时间 (ms) | 4.253 | 4.229 | 4.188 |
| 精确预编译 CDMC 总时间 (ms) | **3.809** | **3.962** | **3.704** |
| 混合 → 预编译 mean 场误差 (%) | 0.0101957 → 0.0101969 | 0.0089892 → 0.0089900 | 0.0571086 → 0.0571062 |
| 混合 → 预编译一次网格计划 (ms) | 223 → 4055 | 220 → 2718 | 222 → 3044 |
| 混合 → 预编译 PyTorch 峰值已分配显存 (MiB) | 28.22 → 145.67 | 26.52 → 97.69 | 26.25 → 108.76 |

正式计时的总时间改善分别约 **10.4% / 6.3% / 11.6%**，没有达到“大幅加速”的目标。三组各 16 样本另加一个非零边界样本的 CPU/混合/预编译层矩阵检查全部通过；混合与预编译之间最大的逐层矩阵相对 Frobenius 差低于 $3.9\times10^{-7}$；K=2 逐样本误差差异最大低于 $4.0\times10^{-5}$ 个百分点。主要代价是离线单元投影表的准备与存储：仅凭当前小网格的热态收益，需固定网格数千次查询才可能抵回额外准备时间，且尚未验证大网格显存可扩展性。

同样本上的成熟 CPU P1-FEM 稀疏直接法约为 3.47/2.91/2.87 ms（规则/不规则/OOD），并求出同网格真值；预编译 CDMC 在这组约千节点样本上**尚未赢过直接数值解**。这也是不能把本次 6%–12% 局部改进表述为求解器速度优势的原因。

该精确构造依赖 Darcy 当前单元局部矩阵对系数的线性性；其他 PDE 需由离散适配器提供相应局部参数展开，非线性 Jacobian 不能自动套用本映射。因此这里验证的是*适配器可提供局部线性展开时*的离线—在线模式，并未验证一般 PDE 的精确预编译。

## 2. 用一次神经多尺度方向替换两轮数值校正

在冻结的 NO 初值 $x_0$ 上形成真实残差 $r_0=b-Ax_0$。实验模型用参考图上两层消息传播，根据系数/质量/矩阵对角和归一化残差输出细尺度、粗尺度门控。各层原始缺陷 $r_\ell=R_{\ell-1}\cdots R_0r_0$ 逐层限制，但**不根据前一级修正更新缺陷**；中间层仅用对角近似，末层保留现有精确小矩阵逆。各层修正延拓相加成一个方向 $d_\theta$，最后只做一次原有 SPD 能量步长 $\alpha=(r_0^\top d_\theta)/(d_\theta^\top A d_\theta)$。没有 V-cycle 前后平滑或第二次残差更新。

规则和不规则各自训练一次：64 训练 / 16 验证，16 epoch 按验证误差选权重，随后在各 16 个测试样本与原 CDMC K2 同进程计时；凹口 OOD 直接复用不规则 ID 权重。

| 方法；mean 场误差 (%) / 热态总时间 (ms) | 规则 ID | 不规则 ID | 几何 OOD |
| --- | ---: | ---: | ---: |
| 固定 MG 一轮，从 NO 起步 | 0.385 / 3.027 | 0.328 / 2.987 | 2.100 / 2.997 |
| **一次神经多尺度方向** | 1.636 / 3.022 | 1.972 / 2.980 | 9.745 / 2.989 |
| 原 CDMC 两轮，同次实验 | **0.0102 / 4.054** | **0.00899 / 4.033** | **0.0571 / 4.049** |

**判定：不通过。** 它比一轮固定 MG 的精度还差，不能作为正式方法，也不能通过混入一次残差计算来声称同精度提速。保留独立原型仅供检查失败机理。

进一步的容量诊断：将 64 个训练样本的 *NO + 一轮固定 MG* 的真实误差作质量加权 SVD。用测试集真值选择最优投影系数——这是现实推理无法取得的**乐观下界**——仅用前 8/16/32/64 个固定误差方向时，规则测试 mean 场误差仍为 0.189%/0.171%/0.147%/0.121%，远高于 CDMC 两轮 0.0102%。所以仅增大当前固定的小误差字典并不能弥合差距；该实验**不能排除**由每个新样本自适应生成高维方向、或使用更大训练集和不同模型架构。

另测试保持既有 CDMC 权重、只把最粗层目标从 128 提到 256/512：一轮误差分别 0.207% / 0.191% / 0.199%，总时间分别 3.40 / 3.69 / 5.31 ms；单纯让粗层更精确既不达到目标精度，也不缩短总时间。该阈值诊断**没有重新训练权重**，不可用来比较重新训练的大粗层模型。

## 3. 结论和下一次方法门槛

本轮保住精度的变动只有精确预编译，热态总时间改善约 6%–12% 且冷启动/显存变差；少一轮和当前轻量一次方向均失去约两个数量级的精度。因此目前没有获得“显著加速且维持两轮精度”的新主线，正式 `auto`、训练和 results/current 均不变。

下一条值得研究的不是继续加粗层或再给当前门控调参，而是**样本自适应的多维误差空间**。具体候选是：图消息传递表达局部高频，粗图的全局信息交换表达长程低频，交互网络对当前 $A$、NO 初值及残差生成数个互补方向 $U_\theta=[d_1,\ldots,d_q]$；用在线小矩阵 $U_\theta^\top A U_\theta$ 的 Galerkin 解确定各方向系数，而不是像本轮实验那样让固定的细/粗 Jacobi 分支全部共享一个步长。网络必须在训练时同时学习 NO 缺陷和数值两轮的阶段性错误，并用不同方向的正交/互补诊断判别是否真正覆盖漏掉的误差模态。这里的自适应方向与上面的**固定 64 维误差字典**不同，但目前仅是待验证假设，既不宣称精度，也不宣称可跨 PDE 直接复用。

接受门槛是同数据上同时满足 mean/P95 场误差不差于 CDMC K2，含在线系统的 batch=1 热态时间显著低于它，并另列冷启动、GPU 显存和非规则几何；若 $q$ 个方向带来的 $q$ 次 $A d_j$ 超过省下的一轮 V-cycle，则从复杂度上直接否决。达到这些条件之前不把任何一次预测升级为 v2 正式方案。
