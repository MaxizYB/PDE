# CDMC v2 新网格构建扩展性审计（2026-09-28）

本页记录**优化前的构建方式**及其瓶颈；[后续优化和最新结果](MESH_PLAN_OPTIMIZATION.md)已将 66,049 节点的完整构建跑通，耗时 46.54 秒。原始实现不能把约千节点网格上的每网格 1–2 秒准备时间外推到大网格：当时稀疏层级虽能在 66,049 节点上建立，但已需 52.81 秒；完整路径在 4,225 节点上超过 90 秒限时，主要受稠密投影映射预编译制约。

## 测试范围与结果

使用服务器 gtmsmw 环境、单张 RTX 4090、规则三角 P1 网格；只构造网格计划，不生成训练样本，不运行 NO/CDMC 推理。测试进程限制为该 GPU 总显存的 15%，每个规模独立启动；超过限时即终止。节点数和三角形数由相同的 `regular_mesh` 生成。GPU 和进程内存是 PyTorch 峰值 allocated 及进程最大 RSS，非全服务器占用。

| 网格 | 节点 / 三角形 | 执行范围 | 构建时间 | GPU 峰值 | 进程 RSS 峰值 |
| --- | ---: | --- | ---: | ---: | ---: |
| 33×33 | 1,089 / 2,048 | 完整 `PartialGalerkin` | 2.673 s，其中投影映射 1.810 s | 113 MiB | 1,084 MiB |
| 65×65 | 4,225 / 8,192 | 仅稀疏层级 | 0.311 s | 6.6 MiB | 565 MiB |
| 65×65 | 4,225 / 8,192 | 层级 + 稠密跨层基 | 0.860 s，其中跨层基 0.537 s | 127 MiB | 614 MiB |
| 65×65 | 4,225 / 8,192 | 层级 + 参考系统（旧 CPU 路径） | 1.019 s，其中参考系统 0.701 s | 11 MiB | 567 MiB |
| 65×65 | 4,225 / 8,192 | 完整 `PartialGalerkin` | **90 s 未完成，限时终止** | 未测得 | 未测得 |
| 129×129 | 16,641 / 32,768 | 仅稀疏层级 | 3.813 s | 46 MiB | 625 MiB |
| 257×257 | 66,049 / 131,072 | 仅稀疏层级 | 52.810 s | 307 MiB | 1,013 MiB |

这些是单次墙钟观察，不是稳定性能均值；特别是千节点完整计划曾在另一轮测试中为约 1.1–1.5 秒。65×65 的完整运行未输出分段结果；另一次明确打印阶段的测试中，层级用 0.218 秒、稠密跨层基用 0.459 秒，随后进入投影映射编译，**25 秒内未完成**。参考系统单独构建用 0.701 秒。故已定位主要阻塞为投影映射编译；但尚未得到它的完整耗时，不能把“90 秒未完成”写成恰好 90 秒。参考系统行采用另一条旧 CPU 路径，**不能**与跨层基行简单相加当作新方案总时间。

## 结构原因与安全边界

当前 `ImplicitGalerkin` 首先保存 $Q_0=I$ 的稠密 GPU 张量，并保存后续跨层基 $Q_\ell$；`compile_diag_terminal_maps` 还会逐层生成稠密的单元基切片，再筛选其中的非零贡献。这使得尽管最终映射可用稀疏格式保存，**映射编译过程仍经过规模约为 $O(N^2)$ 的中间表示**，其中 $N$ 是自由节点数。

| 规则网格 | 自由节点 | 单独 $Q_0$ 的 float32 空间 | 全部稠密跨层基粗估 |
| --- | ---: | ---: | ---: |
| 129×129 | 16,129 | 0.97 GiB | 约 1.94 GiB，未计编译临时张量 |
| 257×257 | 65,025 | 15.75 GiB | 约 31.5 GiB，未计编译临时张量 |
| 513×513 | 261,121 | 254 GiB | 约 508 GiB，超过单卡容量 |

因此没有在 66,049 或 263,169 节点上冒险运行完整路径。前者只测到稀疏层级，后者只做内存估算。测试脚本 `experimental/mesh_plan_scaling_probe.py` 默认限制 GPU 进程占比 15%、总节点 70,000、完整投影映射自由节点 2,048；另在稠密基估算超过 3 GiB 时预先拒绝。65×65 的受控超时测试是在加装投影映射节点限制**之前**完成的，不会在默认设置下再次执行；90 秒限时测试结束后无残留 GPU 任务。

这组失败说明**审计时的“稠密 $Q_\ell$ + 逐单元投影映射”执行实现不适合大网格或每样本新几何**。后续已改用稀疏传递链，并取消大规模的精确映射编译；新路径的构建与小网格推理实测见[优化报告](MESH_PLAN_OPTIMIZATION.md)。

原始 JSON 位于 `results/performance/matrixfree_20260928/scale_*.json`。完整 65×65 及单独 maps 阶段超时均没有 JSON；对应终止码为 124，阶段打印记录在执行日志中。此前约千节点热态精度和速度结果见 [矩阵无关 CDMC 预览](CDMC_MATRIXFREE_VCYCLE_PREVIEW.md)，不能用本页稀疏层级时间替代完整方法的准备时间。
