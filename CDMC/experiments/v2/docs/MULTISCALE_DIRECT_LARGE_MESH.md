# v2 多尺度训练与 257×257 留出测试：同一无 PCG V-cycle

日期：2026-09-29。本实验沿用 Darcy P1-FEM、冻结的 Geo-FNO 初值、图网络门控和两轮 Galerkin V-cycle。训练及评测均调用 `solver/matrixfree_cdmc.py` 的同一个矩阵无关校正函数；各层算子作用来自当前系数样本，最底层的小 Galerkin 系统由当前样本精确构造并用 Cholesky 直接解。中间层 Jacobi 对角线仍采用 v2 的参考层级尺度近似。**本实验不使用 PCG。**

## 训练与数据边界

| 用途 | 网格 | 样本数 train/val/test | 数据种子 | 多重网格层数 |
| --- | ---: | ---: | ---: | ---: |
| 多尺度训练 | 33×33 | 64/16/16 | 20260927 | 4 |
| 多尺度训练 | 65×65 | 64/16/16 | 20260930 | 6 |
| 多尺度训练 | 129×129 | 32/8/8 | 20261001 | 8 |
| 最终留出测试 | 257×257 | 1/1/12；仅使用 test 的 12 个 | 20271003 | 10 |

所有样本使用同一规则方形 Darcy 系数生成规则、零 Dirichlet 边界和同网格 P1-FEM 真值。257×257 的 train/val 文件只是生成器产物，未用于本次训练或选模；更早的另一个种子 20271001 的三个 257×257 样本曾用于识别粗层门控问题，因此本页使用新种子进行最终测试。新测试集保存真值的最大相对离散残差为 $3.342\times10^{-12}$。

Geo-FNO 继续使用原 33×33 权重并冻结。CDMC 图网络由原 33×33 checkpoint 初始化，同一组参数在三个训练尺度上共享。每轮每个尺度随机取 16 个训练样本，按尺度均衡混合，展开完整两轮 V-cycle；本轮只训练平滑门控，跨层粗网格门控固定为 1。训练损失是第二轮相对 FEM 解场误差；每尺度取 8 个独立验证样本，以三尺度平均第二轮误差选 checkpoint。训练 16 epoch，最佳为第 5 轮，三尺度平均验证误差 **0.01328%**。每个 epoch 的优化与验证约 4.9 秒，不含样本准备及一次性网格计划。

## 从数据到权重：实际训练流程

1. **固定初值模型。** 加载此前在 33×33 Darcy 上训练的 Geo-FNO，不更新它的参数。对每个训练/验证样本先计算完整场初值 $u_0$，随后仅取自由节点进入校正器。33×33 的 CDMC 训练样本来自 Geo-FNO 曾使用的同一训练分割；65×65、129×129 则使用另两个种子生成的样本。每个尺度的验证、测试分割均独立于其训练分割。
2. **构造当前样本的线性系统。** 同一张网格的几何计划只建立一次；每个系数样本单独构造 FEM 右端项、细层算子作用和 128 维末层 Galerkin 矩阵，末层由 Cholesky 精确解。中间层算子作用是 $A_\ell=R_0\cdots R_{\ell-1}A_0P_{\ell-1}\cdots P_0$，以传递链隐式计算；Jacobi 对角线是参考层级尺度近似，而非逐样本精确中间层对角线。这些定义在训练和测试中相同。
3. **预测门控并完整展开求解。** 计算初始离散缺陷 $r_0=b-A_0u_0$。两层图消息传递网络读取节点物理特征与归一化缺陷，每个样本**只调用一次**，产生细层平滑门控；该门控通过正权重限制传播至各层，供两轮 V-cycle 复用。此版本的粗层门控恒为 1。每层做两次前平滑、一次粗层修正、两次后平滑；每一轮结束后再用当前细层算子计算受限的能量步长。网络没有逐层、逐轮重复推理，但其参数梯度贯穿两轮完整 V-cycle。
4. **监督与选模。** 以第 2 轮输出 $u_2$ 相对于**同一网格 P1-FEM 离散解** $u_h^*$ 的质量加权相对场误差作损失：$\mathcal L=\sqrt{\sum_i m_i(u_{2,i}-u^*_{h,i})^2/\sum_i m_i(u^*_{h,i})^2}$。每个 epoch 随机抽取 33/65/129 各 16 个训练样本，共 48 次单样本参数更新；共运行 16 epoch。每个尺度取 8 个验证样本，三尺度等权平均的 K2 误差决定 checkpoint。最优为第 5 个 epoch，即该 checkpoint 经历了 240 次本轮参数更新；其分尺度验证误差依次为 **0.01003% / 0.01606% / 0.01375%**。

这里的“同一训练/测试路径”指算子构造、末层解法、门控使用方式、两轮 V-cycle 和误差定义一致；**不意味着层数相同**。训练网格分别为 4、6、8 层，257×257 测试网格为 10 层。新训练是从旧 33×33 CDMC 权重**微调**，不是随机初始化从零训练。

## 大网格测试如何进行

最终 257×257 数据采用新种子 20271003；生成器虽然同时写出了 train/val 各 1 个样本，本实验只读取其 test 的 12 个样本。此前另一种子下的 3 个 257×257 样本用于诊断粗层门控及选择本轮设计，因此“未见”指**最终 12 个系数样本未参与训练、验证、选权重**，不表示整个 257×257 尺度从未被用于方法诊断。

逐样本先用同一冻结 Geo-FNO 产生 $u_0$，构造当前系数对应的系统。三个校正对照共用该系统、网格层级、末层直接解和两轮预算：**零初值 MG** 从自由节点 $x_0=0$ 开始，**NO+固定 MG** 从 NO 的自由节点初值开始，两者门控均为 1；**NO+CDMC** 从相同 NO 初值开始，使用学习平滑门控。边界值始终由同一样本的边界延拓保留，因此零初值指零自由节点。K1/K2 是第一/第二轮后的场误差，不是图网络调用次数。最后与保存的同网格 FEM 解比较，并另外对 12 个样本重跑一次 SciPy 稀疏直接 FEM 以核对目标和测量其 CPU 耗时。

## 主实验：统一路径下的留出误差

指标均为相对同网格 FEM 真值的质量加权场 $L^2$ 误差，单位百分比。两个带 NO 的校正器使用相同初值；全部 MG/CDMC 行都使用相同 V-cycle 数值核和精确末层直接解。固定 MG 将平滑和跨层门控全部置为 1。

| 测试网格 | 样本数 | NO | 零初值 MG K1 / K2 | NO+固定 MG K1 / K2 | NO+CDMC K1 / K2 | CDMC 相对 NO+MG 的 K2 降误差 | CDMC K2 逐样本胜出 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 33×33 | 16 | 7.1982 | 1.29170 / 0.24929 | 0.37436 / 0.01907 | 0.36740 / **0.01182** | **38.0%** | 16/16 |
| 65×65 | 16 | 6.6245 | 1.16345 / 0.21895 | 0.75206 / 0.02200 | 0.60939 / **0.01350** | **38.7%** | 16/16 |
| 129×129 | 8 | 7.7755 | 1.00466 / 0.18000 | 1.20005 / 0.02950 | 0.95386 / **0.01830** | **38.0%** | 8/8 |
| **257×257（未见尺度）** | **12** | **9.0775** | **1.05346 / 0.16027** | **1.23325 / 0.02820** | **1.00212 / 0.01929** | **31.6%** | **12/12** |

零初值 MG 是在相同测试样本上补跑的数值对照。257×257 的同次复测得到 NO+固定 MG K2 **0.0282049%**、NO+CDMC K2 **0.0193037%**；与原表 **0.0282018% / 0.0192929%** 的差别分别为约 $3.1\times10^{-6}$ / $1.1\times10^{-5}$ 个百分点，故表中保留原最终结果的舍入值。该尺度上，从零初值改用 NO 初值，使固定 MG K2 的平均误差降低 **82.4%**；在相同 NO 初值上加入 CDMC 学习设置，再降低 **31.6%**。129×129 和 257×257 的零初值 MG K1 均值略小于 NO+MG K1，但 K2 关系反转，说明初值作用必须按完整固定预算评价。

此前完整粗层门控在大网格失利。本次在同一批 12 个新测试样本、同一无 PCG 数值路径上复核其影响：

| 门控配置 | 257×257 K2 mean 场误差 | 优于固定 MG 的样本数 |
| --- | ---: | ---: |
| 多尺度训练、完整平滑与粗层门控 | 0.05643% | 0/12 |
| **同一完整门控权重，仅测试时固定粗层门控** | **0.02037%** | **12/12** |
| 多尺度训练、只学习平滑门控并以 K2 场误差监督 | **0.01929%** | **12/12** |
| 固定 MG | 0.02820% | 对照 |

第二行与第一行使用**相同权重**，只改变粗层门控是否起作用，因此能直接定位这批大网格样本上的误差来源。最后一行之外的两个训练模型还使用了不同损失权重，不能把 0.02037% 至 0.01929% 的差值单独归因于网络结构。

## 时间与数值核对

257×257 测试有 66,049 个总节点、65,025 个内部未知量和 10 层层级；末层为 128 个未知量。抽样对照中，在线精确末层矩阵与因子化 Galerkin 作用的相对差约 $3.8\times10^{-6}$。本页为 RTX 4090 GPU 上 batch=1 的 eager 计时；CPU FEM 使用同一服务器成熟 SciPy 稀疏直接求解器，包含装配、边界处理及求解。

| 同一批 257×257 样本 | 平均时间 |
| --- | ---: |
| 一次性网格计划 | 34.4 s / 网格 |
| 在线样本系统与精确末层构建，排除首样本预热 | 2.30 ms |
| CDMC 两轮校正，排除首样本预热 | 32.37 ms |
| 固定 MG 两轮校正，排除首样本预热 | 31.55 ms |
| CPU 稀疏直接 FEM，12 样本平均 | 442.17 ms |

在线构建加两轮 CDMC 的**预热后 11 样本均值**约 **34.67 ms**，此项**未包含 NO 推理和 CPU 输入搬运**。若将首样本也计入，12 样本的构建与校正均值分别为 9.16 ms 和 35.89 ms，合计约 45.05 ms。训练日志中 16 epoch 的优化/验证循环合计 **78.56 s**，不含初始 NO 预测、样本系统准备及网格计划，因此不是完整训练墙钟。FEM 运行于 CPU，不能把 GPU 与 CPU 两列直接解释为同硬件加速倍数。当前无 PCG 分支尚未做 CUDA Graph 捕获。对每个样本都更换全新网格的任务，一次性 34.4 秒网格计划必须计入；固定网格多系数重复查询时才可摊销。

## 与本轮要求逐项核对

| 此前要求 | 核对结果 | 准确边界 |
| --- | --- | --- |
| 不再以 4 层/旧末层解法训练，却用 10 层/另一解法测试 | **本轮满足** | 三个训练尺度与 257 测试均走同一隐式 Galerkin、当前样本末层直接解和两轮 V-cycle；层数允许随网格变化。 |
| 训练时使用整个 V 体系，而非只训练单层门控代理 | **满足** | 训练损失作用在完整两轮输出，梯度穿过所有层和两轮；网络只在初始缺陷处推理一次，门控跨层、跨轮复用。 |
| 不额外依赖 PCG 才获得结果 | **满足** | 此分支末层使用 128 维直接 Cholesky，无末层或全局 PCG。旧的 `evaluate-compiled` 仍是另一条两步末层 PCG 路径，不能与本结果混记。 |
| 测试未参与训练的大网格，比较同条件数值方法 | **样本层面满足** | 257 的新种子 12 个测试样本未用于训练/验证/选权重；同初值、同两轮、同数值核的固定 MG 与 CDMC 逐样本对比。之前另一种子的 3 个 257 样本曾用于选择关闭粗层门控，因此这不是完全未接触 257 尺度的盲测。 |
| 全部训练历史都使用统一新路径 | **未完全满足** | 本轮从旧 33×33 CDMC checkpoint 微调；虽然本轮所有梯度更新使用新路径，旧初始化来自先前数值后端。尚未做从随机初始化的同路径对照。 |
| 证明对一般几何/PDE 及端到端速度的优势 | **尚未验证** | 目前只有规则 Darcy、同网格 FEM 离散真值和 12 个大网格测试样本；GPU 热态计时未包含 NO、输入搬运及冷网格计划。 |

因此，本轮最直接的结论是：**统一执行/训练路径后，同一个 CDMC 参数组可从最多 129×129、8 层的训练网格外推到 257×257、10 层，在这 12 个规则 Darcy 留出样本上优于同骨架固定 MG。** 它还不是从零训练、几何泛化或完整端到端加速的证明。
