# CDMC v2 Darcy：现行实验与归因

本页保留 v2 原逐样本装配后端的主实验、消融与归因，主表和时间拆分来自 2026-09-28 固定权重、默认 GPU 混合后端的三几何评测。现已接入更快的矩阵无关正式推理后端；其同 GPU 复测、网格计划构建规模与对应原始结果统一见[当前阶段整理](CURRENT_STAGE.md)。下方历史主表不与新后端的不同运行轮次直接计算加速比。

## 设置与指标

| 条件 | 规则 ID | 不规则 ID | 几何 OOD |
| --- | ---: | ---: | ---: |
| 域 / 网格 | 单位方形，33×33 顶点剖成 P1 三角形 | 顶部凹口，宽 0.16、深 0.68 | 凹口宽 0.25、深 0.50 |
| 顶点数 | 1089 | 938 | 909 |
| 训练 / 验证 / 测试 | 64 / 16 / 16 | 64 / 16 / 16 | 0 / 0 / 16；复用不规则 ID 权重 |
| 数据种子 | 20260927 | 20260927 | 20270927 |

三组均为 $-\nabla\cdot(a\nabla u)=1$、$a\in\{3,12\}$、零 Dirichlet 边界。真值为同网格 P1-FEM 稀疏直接解。NO 训练 30 epoch，CDMC 训练 8 epoch，按验证集选 checkpoint；规则与不规则分别训练。当前使用固定网格 Geo-FNO 几何基缓存与 CUDA Graph、GPU 编译装配、逐样本精确 Galerkin、粗层阈值 128、每层预/后各两次 Jacobi。CUDA 默认混合后端保留细层稀疏矩阵，大小不超过 512 的层及其传递算子使用稠密 GPU 运算，粗层使用默认显式逆；不改变模型与离散问题。数据是项目自生成 pilot，不是 Geo-FNO/NORM/LRSA 论文原始集。

误差为质量加权相对场 $L^2$，单位百分比；P95 是 16 个单样本误差的第 95 百分位。时间为同服务器 RTX 4090 GPU 上预热后、batch=1、CPU 新样本输入、逐样本同步墙钟均值；FEM 直接法使用同服务器 CPU。NO、MG 与 CDMC 的端到端热态时间不含一次性网格计划和图准备。不要把这一口径与 batch=16 GPU 常驻输入的吞吐数字并列比较。

## 主结果

每格为“mean 误差% / P95 误差% / 端到端 ms”。$K$ 为固定 V-cycle 轮数，MG 与 CDMC 共用同一层级和内核。

| 方法 | 规则 ID | 不规则 ID | 几何 OOD |
| --- | ---: | ---: | ---: |
| Geo-FNO 单次 | 7.199 / 13.079 / **0.336** | 5.669 / 9.305 / **0.335** | 35.303 / 40.569 / **0.332** |
| 固定 MG，零初值，K=1 | 1.371 / 1.616 / 2.850 | 2.645 / 3.471 / 2.797 | 2.515 / 3.210 / 2.777 |
| 固定 MG，零初值，K=2 | 0.2710 / 0.3220 / 3.495 | 0.3743 / 0.4915 / 3.447 | 0.3645 / 0.4689 / 3.413 |
| 固定 MG + NO，K=1 | 0.3846 / 0.5954 / 3.155 | 0.3277 / 0.5644 / 3.100 | 2.0996 / 2.8934 / 3.070 |
| **CDMC + NO，K=1** | **0.2072 / 0.2954 / 3.590** | **0.1386 / 0.2412 / 3.556** | **0.7897 / 1.1591 / 3.527** |
| 固定 MG + NO，K=2 | 0.02043 / 0.03071 / 3.820 | 0.01825 / 0.02708 / 3.758 | 0.16119 / 0.24581 / 3.729 |
| **CDMC + NO，K=2** | **0.01020 / 0.01667 / 4.253** | **0.00899 / 0.01472 / 4.229** | **0.05711 / 0.10177 / 4.188** |
| P1-FEM 稀疏直接法 | ≈0 / ≈0 / 3.474 | ≈0 / ≈0 / 2.911 | ≈0 / ≈0 / 2.875 |

在相同 NO、相同层级、相同 $K=2$ 下，图神经设置相对固定 MG 将 mean 场误差降低约 **50.1% / 50.7% / 64.6%**（规则 / 不规则 / 几何 OOD），端到端各增加约 0.43–0.47 ms。NO 初值并不保证每个阶段都比零初值好：尤其 OOD 的 NO 误差较大，MG 从零 K2 可优于 MG 从 NO K2。CDMC 则在这个 OOD 集上把 NO 初值产生的误差明显压低。当前小网格上，直接稀疏法仍更快且与同网格真值一致；该试验体现的是**固定轮数下更有效的 NO 缺陷设置**，而非最快的小网格求解。

## 同权重、同样本后端 A/B

下面两条路径仅改变 Galerkin 小矩阵的计算表示；旧 gpu_compiled 全层采用稀疏 GPU 路径，新 gpu_hybrid 对小层及传递使用稠密 GPU 路径。均为同一 RTX 4090、16 个样本、batch=1、默认显式逆、NO/CDMC 相同权重和 K=2；两者都逐样本构造真实 $A_{\ell+1}=R_\ell A_\ell P_\ell$。不同进程的墙钟有波动，A/B 改善量仅按此轮实测报告。

| 几何 | 在线系统旧 → 新 (ms) | CDMC K2 热态总计旧 → 新 (ms) | CDMC K2 mean 误差旧 → 新 (%) | 网格计划旧 → 新 (ms/次) | 峰值已分配显存旧 → 新 (MiB) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 规则 ID | 2.748 → 1.931 | 5.345 → 4.253 | 0.0101952 → 0.0101957 | 139.8 → 223.3 | 44.46 → 28.22 |
| 不规则 ID | 2.689 → 1.878 | 5.281 → 4.229 | 0.0089890 → 0.0089892 | 135.1 → 220.0 | 38.59 → 26.52 |
| 几何 OOD | 2.685 → 1.858 | 5.289 → 4.188 | 0.0571116 → 0.0571086 | 134.9 → 222.1 | 41.59 → 26.25 |

三组热态总时间分别下降约 20.4%、19.9%、20.8%。每组 CDMC K2 逐样本最大误差差别低于 $3.4\times10^{-5}$ 个百分点；在线系统快约 0.81–0.83 ms。网格一次性计划慢约 84–87 ms，故优化适合固定网格重复求解，不能推广为冷启动单次加速。峰值字段是本次评测窗口的 PyTorch *allocated* 显存，不是 nvidia-smi 全卡显存，也不是工业级网格显存上界。相同混合后端改用 Cholesky 粗层后总时间为 4.213/4.173/4.204 ms（规则/不规则/OOD），三组并非一致优于默认逆，故保持显式逆为默认。

## 为什么保留当前主干

以下消融固定现有 NO/CDMC checkpoint，不重新训练。误差为 mean 场误差百分比；原实验的时间差取自旧 gpu_compiled 路径，**仅用于同组消融对照**，不得与上面混合后端主表的绝对时间相减。误差结论仍可沿用；不同后端的小幅时间差需重新测量。

| 改动 | 规则 ID | 不规则 ID | 几何 OOD | 观察 |
| --- | ---: | ---: | ---: | --- |
| 消融基准 CDMC K2（旧后端计时） | **0.0102** | **0.0090** | **0.0571** | 约 5.3 ms |
| 聚合每组最多 4 节点 | 0.0468 | 0.0268 | 0.3850 | 省约 1.1–1.3 ms，但粗化误差明显增大 |
| 聚合每组最多 8 节点 | 0.0502 | 0.0744 | 0.8872 | 同样失去 OOD 精度 |
| 每层预/后平滑各 1 步 | 0.0657 | 0.0527 | 0.2552 | 省约 0.4 ms，误差显著上升 |
| 参考粗算子按均值系数缩放 | 1.0296 | 0.7736 | 5.1796 | 不再保持本样本 Galerkin 一致性 |
| 固定 MG，去掉图 setup | 0.0204 | 0.0182 | 0.1612 | 约省 0.5 ms，但精度下降 |
| 只保留平滑门控 | 0.0145 | 0.0103 | 0.1025 | 节时 <0.04 ms |
| 只保留粗层门控 | 0.0227 | 0.0185 | 0.1276 | 节时 <0.04 ms |
| 能量步长改为固定 1 | 0.0247 | 0.0086 | 0.0753 | 不同几何表现不一致，约省 0.18 ms |

门控单项删减只说明**现有权重下直接删**的结果；未重训的删减不能作为完整模型容量比较。此前唯一无损删去的重复计算是 $|R_\ell|\mathbf1$：把它从每样本 setup 移到固定网格计划后，旧后端三组 CDMC K2 由 5.397/5.323/5.360 ms 降至约 5.257/5.264/5.228 ms；误差只有 GPU 稀疏求和舍入量级变化。新后端又在相同模型上独立降低了热态延迟，见 A/B 表。

## 执行路径与数值一致性

规则网格固定权重、同 16 样本，NO reference / 预计算几何基 / 预计算基加 CUDA Graph 的 CPU 新输入延迟分别是 2.702 / 2.037 / 0.367 ms；新主表重新测得 0.336 ms。原始图推理与参考推理逐点最大绝对差为 0。固定拓扑 GPU 系统构建把三几何原 CPU 在线构建约 8.05/8.01/8.35 ms 降至旧后端约 2.7 ms；新混合后端再降至约 1.9 ms。CPU 与旧 GPU、旧 GPU 与混合 GPU 均对三几何各 16 个样本及一个非零边界样本核验：新旧 GPU 逐层矩阵最大相对 Frobenius 差不超过约 $2.2\times10^{-7}$，右端和节点特征相同。加速只改执行路径，不改已训练权重或离散目标。

数值内核早期曾有粗层 Jacobi 阻尼失稳；修复采用每层样本矩阵的谱上界，并把粗层阈值设为 128，固定 MG 与 CDMC 均按同一新内核重训/复测。验证脚本在三测试集共 96 个 CDMC 更新方向中检查到非正 $r^\top d$ 0 次、能量反增 0 次、手工追踪与正式更新不符 0 次。旧版结果仅留在 archive 中用于回归定位。
