# CDMC v2 阶段总结：统一方法、Darcy 多尺度实验与计算成本

后续执行优化（2026-10-10）：局部传递快速计划已接入原v2入口，同网格257×257成对复测的完整构建由42.97 s降至5.43 s，两轮mean误差从0.01929%变为0.02033%。该选项不改NO/图设置模型、不增加轮数，默认精确路径仍保留。下文保留9月29日的历史配置和计时；新数学定义、精度代价、分段耗时与入口见[快速网格计划报告](MESH_PLAN_FAST_MODE_20261010.md)。

日期：2026-09-29。**本页以最后完成的「多尺度训练、只学习平滑门控、当前样本末层直接解、两轮 V-cycle」为 v2 当前最终配置。** 早期逐层装配版及末层两步 PCG 的矩阵无关版是建立这一配置的对照和技术验证；它们的权重、训练路径、计时口径不能和最终配置直接拼成一张“同次实验”表。

## 1. 一句话定位与研究问题

CDMC v2 是一个**固定计算预算的 NO 驱动多重网格后求解器**：神经算子给出初始场，真实离散方程给出初始缺陷，图网络根据这个缺陷设置多重网格平滑，随后固定执行两轮数值一致的 V-cycle。它研究的是“在给定两轮校正的预算下，怎样利用 NO 特有的剩余误差，使同一数值骨架比固定 MG 更准确”，而不是把图网络称为一个独立的精确 PDE 求解器。

主流程为：

`网格/系数/边界 → Geo-FNO 初值 → 与数据一致的离散系统 → 初始缺陷 → 一次图网络设置 → 两轮 Galerkin V-cycle → 完整场`

它把两种方法的职责分开：NO 快速提供全局近似；数值层级执行跨尺度误差传播与物理一致的修正；学习模块专门设置 NO 遗留缺陷的**局部平滑强度**。本轮大网格实验进一步确定：跨层粗网格传递保持数值原样，比在所有深层重复施加学习门控更稳健。

## 2. 统一的数学与物理接口

从更一般的离散 PDE 看，稳态问题、隐式时间步或非线性问题在给定状态后都能形成一个离散残差 $\mathcal R_h(x;\mu)$。线性问题直接写作 $A_hx=b_h$；非线性问题在某个状态 $x^{(j)}$ 处形成切线子问题 $J_h(x^{(j)})\delta=-\mathcal R_h(x^{(j)})$。因此统一对象是**离散代数误差修正**，不是要求不同 PDE 共用同一个系数、同一边界或同一训练权重。

当前已经实现和实验验证的内核是 SPD 的 Darcy 系统。Darcy 适配器采用 P1 三角形 FEM，把 $-\nabla\cdot(a\nabla u)=1$ 和 Dirichlet 边界化为自由节点系统 $Ax=b$。其真值 $x_h^*$ 是**同网格、同刚度、同右端**的稀疏直接解，所以本次场误差衡量的是代数求解误差，而非连续 PDE 的空间离散误差。正系数与 Dirichlet 消元使 $A$ 对称正定，允许 Galerkin 粗化、Cholesky 末层解及能量步长。

给定 NO 的自由节点初值 $x_0$，真实离散缺陷与目标修正满足

$$r_0=b-Ax_0,\qquad A(x_h^*-x_0)=r_0.$$

CDMC 不直接回归 $x_h^*-x_0$。它使用一次图网络 $S_\psi$，读取节点系数、细层对角线、坐标、质量和归一化的 $r_0$，产生有界平滑门控 $s_0\in(0.5,1.5)^N$。图网络是**两层邻域消息传递**，不是重新设计 NO 骨干；这一门控用非负传递权重平均到所有粗层，**每个样本只预测一次，供两轮 V-cycle 复用**。当前最终配置的粗层门控固定为 $c_\ell=1$。

网格计划从参考刚度建立固定的稀疏 $P_\ell$ 和 $R_\ell=P_\ell^\top$。对**当前样本**，每层的精确 Galerkin 作用定义为

$$A_\ell(a)v=R_{\ell-1}\cdots R_0\,A_0(a)\,P_0\cdots P_{\ell-1}v.$$

细层 $A_0(a)v$ 按 P1 单元作用计算；中间层不显式装配整张矩阵。Jacobi 对角线用当前细层对角线和参考层级的平方传递近似，它只决定平滑尺度，**不替代上述当前样本的算子作用**。每个非末层执行两次预平滑、一次数值粗层校正和两次后平滑；最末层构造当前样本约 128 维的 Galerkin 矩阵并直接 Cholesky 解。本最终配置没有 PCG。

设这一轮 V-cycle 给出方向 $d_k=B_{\psi}(r_k)$，$r_k=b-Ax_k$。外层用当前 $A$ 计算能量步长并更新：

$$\alpha_k=\operatorname{clip}_{[0,2]}\!\left(\frac{r_k^\top d_k}{d_k^\top A d_k}\right),\qquad x_{k+1}=x_k+\alpha_kd_k,\qquad k=0,1.$$

这是一种**固定两步的 NO 条件化缺陷校正**，不是外层 PCG，也不按误差阈值决定迭代数。SPD 时，离散能量 $E(x)=\tfrac12x^\top Ax-b^\top x$ 沿任意方向的变化为 $E(x+\alpha d)-E(x)=-\alpha r^\top d+\tfrac12\alpha^2d^\top Ad$；上述步长在精确运算下使能量不增加。这给学习门控提供了可解释的数值约束，同时不把“能量下降”误写成“场误差必然逐步单调下降”。

**统一性所在的层次**是 `NO proposal → 对齐的离散缺陷 → 一次学习型多级设置 → 固定预算数值校正`。规则方形与凹口三角网格都能经 Darcy 适配器进入这个主干；早期 v2 已验证两种几何。对其他 SPD 稳态 PDE，可替换离散适配器而保留这一代数骨架。非线性、时域和非 SPD 系统也有相同的“proposal/缺陷/修正”上层接口，但它们的切线系统、约束与稳定数值内核必须分别构造；**本页不把 Darcy 实验写成这些方程已经通过测试**。

## 3. 最终配置怎样训练

| 网格 | 数据 train/val/test | 本轮每 epoch 用于训练/验证 | 多级层数 | 用途 |
| --- | ---: | ---: | ---: | --- |
| 33×33 | 64/16/16 | 16/8 | 4 | 训练、验证和留出测试 |
| 65×65 | 64/16/16 | 16/8 | 6 | 训练、验证和留出测试 |
| 129×129 | 32/8/8 | 16/8 | 8 | 训练、验证和留出测试 |
| 257×257 | 1/1/12 | **0/0** | 10 | **最终 12 样本测试** |

各尺度数据由同一规则 Darcy 生成器产生：单位方形 P1 三角网格，系数为 $\{3,12\}$ 的随机空间场，单位源项、零 Dirichlet 边界；但每尺度使用不同随机种子。Geo-FNO 采用此前在 33×33 上训练的权重，并在本轮**冻结**。CDMC 图网络由此前 33×33 checkpoint 初始化，在 33/65/129 三种尺度上共享同一组参数并微调。训练和测试都使用同一矩阵无关 Galerkin、当前样本末层直接解、两轮 V-cycle 的代码路径；变化的只是网格和随之形成的层数。

一个训练样本先计算 $x_0$，再构造当前样本系统、得到一次门控，完整展开两轮，直接以第二轮场 $u_2$ 对同网格 FEM 解 $u_h^*$ 的质量加权相对误差监督：

$$\operatorname{Rel}_m(u_2,u_h^*)=\sqrt{\frac{\sum_i m_i(u_{2,i}-u_{h,i}^*)^2}{\sum_i m_i(u_{h,i}^*)^2}}.$$

每个 epoch 三尺度各随机取 16 个训练样本，共 48 次单样本更新；共训练 16 epoch。每尺度 8 个验证样本等权选模型，最优为第 5 epoch，其分尺度 K2 验证误差分别是 **0.01003% / 0.01606% / 0.01375%**，均值 **0.01328%**。16 epoch 的优化和验证循环计时为 **78.56 s**；初值预计算、系统准备与每网格一次性计划不在这项训练时间内。初始化来自旧权重，但本轮每次参数更新的反向传播都经过**整个当前 V-cycle**，而非只拟合单层门控。

## 4. 怎样测试，以及最终得到什么

最终 257×257 使用种子 20271003 的 **12 个全新测试系数场**；这些样本不参与训练、验证或 checkpoint 选择。另一个种子的 3 个 257×257 样本此前用于诊断粗层门控，故最终结果是**新样本上的尺度外推测试**，而不是从未观察过该尺度的设计盲测。零初值 MG、NO+固定 MG 与 NO+CDMC 共享相同的 $A,P,R$、末层直接解、每层平滑次数和两轮预算；后两者共享相同 NO 初值，固定 MG 的门控为 1，CDMC 使用学习平滑门控。零初值 MG 的自由节点从 0 开始，边界仍施加当前样本的已知边界值。

下表都是**相对同网格 FEM 直接解的平均场误差**，单位百分比；K1/K2 分别是第一、第二轮 V-cycle 后，而不是神经网络推理次数。

| 测试网格 | 测试数 | NO | 零初值 MG K1 / K2 | NO+固定 MG K1 / K2 | NO+CDMC K1 / K2 | CDMC 对 NO+MG 的 K2 降误差 | 逐样本胜出 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 33×33 | 16 | 7.1982 | 1.29170 / 0.24929 | 0.37436 / 0.01907 | 0.36740 / **0.01182** | 38.0% | 16/16 |
| 65×65 | 16 | 6.6245 | 1.16345 / 0.21895 | 0.75206 / 0.02200 | 0.60939 / **0.01350** | 38.7% | 16/16 |
| 129×129 | 8 | 7.7755 | 1.00466 / 0.18000 | 1.20005 / 0.02950 | 0.95386 / **0.01830** | 38.0% | 8/8 |
| **257×257** | **12** | **9.0775** | **1.05346 / 0.16027** | **1.23325 / 0.02820** | **1.00212 / 0.01929** | **31.6%** | **12/12** |

新增加的零初值 MG 对照把两个收益分开：257×257 上，NO 初值使固定 MG 的 K2 平均误差从 **0.16027%** 降至 **0.02820%**，相对下降 **82.4%**；同一 NO 初值上，CDMC 的学习设置继续降至 **0.01929%**，相对固定 MG 再下降 **31.6%**，12/12 样本胜出。129×129 和 257×257 的零初值 MG 在 K1 均值上略好于 NO+MG，但 K2 明显落后，反映出固定预算完整两轮的必要性。零初值数值对照与原表其余方法在相同样本、同一数值核中复测；257×257 复测的 CDMC K2 为 0.0193037%，与此前 0.0192929% 相差约 $1.1\times10^{-5}$ 个百分点。

门控诊断给出设计原因：同批 257 测试上，完整平滑+粗层门控的 K2 误差为 **0.05643%**；保持同一权重、只关闭粗层门控即为 **0.02037%**；按最终的平滑-only、K2 目标训练为 **0.01929%**。深层传递留给 Galerkin，学习容量放在 NO 遗留局部误差上，是本轮跨 4/6/8/10 层能够成立的关键取舍。

此前 v2 的**不同权重/不同末层配置**还做过 938 节点凹口 ID 和 909 节点凹口几何 OOD：矩阵无关 CUDA 图路径的 CDMC K2 mean 误差分别为 **0.00822% / 0.05131%**，热态完整时间约 **2.02 ms / 2.02 ms**；规则 1089 节点为 **0.01028% / 2.13 ms**。它们证明原 v2 主干与 Darcy 网格适配器曾在不规则几何上工作，**不是本轮平滑-only、末层直接解最终权重的几何 OOD 分数**。这一分界使历史证据和最新主结果各自清楚。

## 5. 时间花在哪里：数值结构的收益与当前成本

最终 257×257 网格有 66,049 个节点、65,025 个自由未知量、131,072 个三角形和 10 层；末层 128 维。RTX 4090 上逐样本、batch=1 的**预热后 11 样本 eager 均值**如下。CPU FEM 是同服务器 SciPy 稀疏装配及直接求解。

| 阶段 | 时间 | 物理/算法工作 |
| --- | ---: | --- |
| 一次性网格计划 | **34.33 s / 新网格** | 参考刚度、聚合、稀疏 $P,R$、参考层级、图及末层投影几何；同网格查询可复用 |
| 每样本在线系统 | **2.30 ms** | 当前系数的单元作用、右端、对角线及当前样本 128 维末层矩阵和 Cholesky |
| CDMC 两轮校正 | **32.37 ms** | 一次图设置、各层前/后平滑、隐式 Galerkin 作用、末层解及两次能量步长 |
| 同骨架固定 MG 两轮校正 | **31.55 ms** | 与 CDMC 相同的数值工作，门控固定为 1 |
| CPU FEM 装配+稀疏直接解 | **442.17 ms** | 同网格同方程的高精度数值对照，12 样本均值 |

因此，**在线系统+CDMC 数值校正为 34.67 ms，图学习设置相对固定 MG 两轮仅多约 0.82 ms**；大头不是图网络，而是重复的跨层数值作用。这个 34.67 ms **尚不包含最终运行中单独计时的 NO 和 CPU 输入搬运**。先前相同 257×257 规模、旧末层 PCG/CUDA 图配置测得共享输入+NO 约 **1.42 ms**，可作为量级参照，不能直接与本轮 34.67 ms 相加冒充同批样本的严格端到端数值。按量级看，当前最终数值后校正仍约为 NO 一次推理的 **二十余倍**；因此它已在固定网格多查询时具有与本次 CPU 直接 FEM 竞争的在线时间，**但还没有达到“仅比 NO 慢一点”**。

这些时间改善沿着一条可追溯的路线获得：原小网格显式装配 CDMC 热态约 **4.19–4.25 ms**，其中在线层级装配约 **1.86–1.93 ms**；矩阵无关、稀疏传递链及 CUDA 图把同旧权重的小网格热态降至约 **2.0–2.15 ms**，且旧配置误差基本保持。更重要的是，旧稠密累计跨层基在 66,049 节点时**仅 $Q_0=I$ 就需约 15.75 GiB**；稀疏链消除了这项 $O(N^2)$ 存储，使 66,049 节点完整求解成为可能。最后将末层两步 PCG 换为当前样本的小系统直接解，并按同一路径多尺度重训，解决了此前大网格 CDMC 输给固定 MG 的精度问题。小网格 CUDA 图和最终大网格 eager 属于**不同配置**，不能把两者时间差单独解释为某项修改的净开销。

### 复杂度与固定网格多查询

令 $N$ 为自由节点数、$T$ 为三角形数、$L$ 为层数、$q$ 为末层维数、$K=2$ 为固定轮数。当前单元细层作用约 $O(T)$；单次粗层作用通过传递链回到细层，几何粗化下约 $O(T+N)$，但**每个层级都反复调用细层作用**，所以两轮 V-cycle 的主量级约 $O(KL(T+N))$，而显式稀疏层矩阵的理想 V-cycle 可接近 $O(K(T+N))$。图设置只运行一次，规模随节点和边近线性增长（固定网络宽度）。当前精确末层构造还存储约 $O(Tq)$ 的投影梯度，并做约 $O(Tq^2)$ 的稠密加权 Gram 运算，另有 $O(q^3)$ 的小矩阵分解。这里 $q\approx128$ 固定时在线可行；未来若放大 $q$，这部分会迅速上升。

这解释了观察到的时间结构：在线系统构建已降到 2.30 ms，**真正的可扩展性瓶颈转为 32.37 ms 的反复隐式细层作用及每新网格 34.33 s 的计划**。就固定网格反复改变系数而言，用本次 CPU FEM 442.17 ms 和热态数值 34.67 ms 粗估，约 **85 次查询**可摊销 34.33 s 的计划；这是当前机器、当前基线的交叉点估计，并非普适工业速度定律。若每次都是全新网格，计划不能摊销；若目标是接近 NO 的延迟，下一轮必须减少重复的细层作用或改变粗层作用表示，单纯再压缩图网络推理不会解决主要开销。

## 6. 明天汇报时的核心结论

1. **方法层面**：CDMC v2 将神经算子初值与 SPD 数值多重网格连接成固定两轮的后求解器；网络学习 NO 实际缺陷的平滑设置，Galerkin 层级负责跨尺度传播，能量步长保证离散能量不增加。这是统一的代数求解接口，Darcy 是已完成验证的实例。
2. **精度层面**：在训练只覆盖至 129×129、8 层时，同一组最终权重外推到 257×257、10 层，12 个新测试样本的平均场误差为 **0.01929%**，比同初值、同两轮固定 MG 的 **0.02820%** 低 **31.6%**。保留数值粗层、只学习平滑，是大网格跨层稳定性的关键设计。
3. **效率层面**：矩阵无关与稀疏传递链消除了原先不可扩展的稠密跨层基；66,049 节点的最终在线系统+两轮校正为 **34.67 ms**，相对本次 CPU 直接 FEM 的 **442.17 ms** 已有多查询潜力。与此同时，校正仍比 NO 单次推理慢二十余倍，34 秒冷网格计划也限制全新几何任务。**当前里程碑是精确的多尺度后求解和固定网格在线效率，不是近 NO 延迟的工业级终点。**
