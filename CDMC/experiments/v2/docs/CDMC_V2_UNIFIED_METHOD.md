## 1. 方法定位与总体流程

CDMC利用神经算子已经获得的近似解，在少量、预先固定的数值校正中继续提高场精度。NO提供全局提议；小型图神经网络根据算子、几何和NO遗留缺陷设置多级平滑；数值层级负责相容的跨尺度误差传播和最终修正。

```text
PDE参数、几何、边界、源项；时域任务另含已知历史
                         │
           PDE适配器：自由度、离散关系、约束与重建
                         │
    ┌────────────────────┴─────────────────────┐
    │ 新网格一次性准备                          │ 每次查询
    │ 参考算子→聚合→局部传递→Galerkin参考层级    │ NO→满足边界的初值
    │ →图/参考尺度/末层投影几何                 │ 当前算子/右端/对角线
    └────────────────────┬─────────────────────┘
                         │
                    初始离散缺陷
                         │
               一次图网络设置→各层平滑门控
                         │
        固定两轮：真实缺陷→完整V-cycle→能量更新
                         │
              自由度还原→约束恢复→完整场
```

统一对象是**离散状态、缺陷、线性误差子问题及其重建**。不同PDE首先经适配器进入这个接口，后面的学习设置和固定轮数多级校正保持同一语义。当前已实现的数值内核针对SPD，即对称正定系统；其他算子性质对应的接入条件在第3节给出。

本方法的身份是**固定轮数的神经—数值后求解器**。多级作用可在数学上视作近似逆，但当前流程没有PCG共轭方向、Krylov正交化或容差触发的延长迭代。

## 2. 统一问题与符号

连续场为$u$，PDE参数、源项及已知上下文统记为$\xi$，网格为$\mathcal T_h$。空间离散和必要的时间离散形成

$$\mathcal F_h(u_h;\xi)=0.$$

消去已知边界或其他可显式处理的约束，用自由未知量$x\in\mathbb R^N$表示场：

$$u_h=E_hx+g_h.$$

$E_h$将自由度注入完整场，$g_h$满足已知约束。当前节点Dirichlet重建中，$g_h$只在固定节点保留边界值，自由节点由$x$决定。数据另存全节点辅助延拓$\gamma_h$供NO输入及预测基底使用，满足$\gamma_h|_D=g_D$；当前非零边界数据采用仿射延拓。它与重建用的$g_h$用途不同，$x$始终表示完整场的自由节点值。消元后的残差和缺陷分别定义为

$$\mathcal R_h(x;\xi)=0,\qquad r(x)=-\mathcal R_h(x;\xi).$$

残差表示“当前状态代入离散方程还差多少”；修正表示“状态需要改变多少”。二者由离散算子连接，不是同一种网络输出。

| 符号 | 含义 |
| --- | --- |
| $x_0,x_k$ | NO自由度初值、第$k$次外层校正后的自由度 |
| $x_h^\star,u_h^\star$ | 当前离散系统的高精度代数解及完整场 |
| $g_h,\gamma_h$ | 约束注入场、NO使用的辅助全节点边界延拓 |
| $A,b$ | 一次线性内核调用中的算子和右端 |
| $r_k=b-Ax_k$ | 该线性调用的当前缺陷 |
| $\ell=0,\ldots,L$ | 空间层号，0为细网格，$L$为末层 |
| $N_\ell,q=N_L$ | 每层未知量数、末层维数 |
| $P_\ell,R_\ell$ | 粗到细延拓、细到粗限制 |
| $A_\ell^{\rm ref},A_\ell$ | 参考层级算子、当前样本层级算子 |
| $s_\ell$ | 网络设置的局部平滑门控 |
| $d_k$ | 第$k$轮V-cycle返回的修正方向 |
| $K,\nu$ | 固定外层轮数、每层预/后平滑次数，当前均为2 |
| $m_P$ | 每行插值项上限，快速配置为64 |
| $W_h$ | 场误差积分权重；当前为集总质量对角阵 |

## 3. 从一般PDE到统一误差子问题

### 3.1 空间离散与边界消元

有限元、有限体积和有限差分都产生离散自由度间的关系。CDMC接收该关系和可计算的算子作用，而不将某一种离散公式写进神经设置主干。

以一般线性弱形式为例，基函数为$\phi_i$，双线性型为$a_\xi(\cdot,\cdot)$，载荷为$\ell_\xi(\cdot)$。将

$$u_h=\sum_j u_j\phi_j$$

代入$a_\xi(u_h,\phi_i)=\ell_\xi(\phi_i)$，得到

$$\sum_j a_\xi(\phi_j,\phi_i)u_j=\ell_\xi(\phi_i).$$

记$\mathsf K_{ij}=a_\xi(\phi_j,\phi_i)$、$f_i=\ell_\xi(\phi_i)$，即$\mathsf Ku=f$。划分自由集合$I$与已知Dirichlet集合$D$：

$$\mathsf K_{II}u_I+\mathsf K_{ID}g_D=f_I.$$

主干因此接收

$$A=\mathsf K_{II},\qquad b=f_I-\mathsf K_{ID}g_D,\qquad x=u_I.$$

有限体积以通量平衡形成相应$A,b$，有限差分以离散微分形成相应$A,b$。决定数值内核能否复用的是消元后算子性质，而不是离散方法名称。

### 3.2 稳态线性：精确误差方程

线性离散残差为$\mathcal R_h(x)=Ax-b$。真解满足$Ax_h^\star=b$，定义代数误差$e_k=x_h^\star-x_k$。相减得到

$$Ae_k=Ax_h^\star-Ax_k=b-Ax_k=r_k.$$

因此误差修复归为$Ae_k=r_k$。CDMC用多级近似作用形成修正方向，不在线完整求逆。

### 3.3 非线性：切线误差方程

非线性关系仍写成$\mathcal R_h(x;\xi)=0$。当Jacobian局部Lipschitz连续时，在状态$z$附近对修正$\delta$展开：

$$\mathcal R_h(z+\delta;\xi)
=\mathcal R_h(z;\xi)+J_h(z;\xi)\delta+O(\|\delta\|^2),$$

其中$J_h$是残差对自由度的Jacobian。使一阶缺陷为零，得到

$$J_h(z;\xi)\delta=-\mathcal R_h(z;\xi).$$

这次线性调用的输入为$A=J_h(z;\xi)$、$b_\delta=-\mathcal R_h(z;\xi)$，从$\delta_0=0$执行固定$K$轮，再由适配器更新$z\leftarrow z+\delta_K$。

若需要多次非线性线性化，重新计算更新状态的残差和Jacobian。**非线性线性化次数和线性内核V-cycle次数是两个独立量**。NO提供接近目标的$z_0$，减轻后续线性化负担。

具有正定切线的变分问题可接入下文SPD内核；其他切线使用相容线性内核。这里给出一般接入的数学定义；当前v2完整定量验证为线性Darcy，非线性包装尚未接入正式实现。

### 3.4 时域：时间离散后的空间调用

一般半离散关系写为

$$M_h\dot x+\mathcal G_h(x;\xi)=f_h(t).$$

后向Euler从$t_n$到$t_{n+1}$给出

$$\frac{M_h}{\Delta t}(x^{n+1}-x^n)
+\mathcal G_h(x^{n+1};\xi)-f_h^{n+1}=0.$$

新时间步的残差为

$$\mathcal R_{h,n+1}(x;x^n)
=\frac{M_h}{\Delta t}(x-x^n)+\mathcal G_h(x;\xi)-f_h^{n+1}.$$

当$\mathcal G_h(x)=\mathsf K_hx$时，直接形成

$$\left(\frac{M_h}{\Delta t}+\mathsf K_h\right)x^{n+1}
=\frac{M_h}{\Delta t}x^n+f_h^{n+1},$$

再进行边界消元。非线性时间步则形成切线算子

$$A=\frac{M_h}{\Delta t}+\partial_x\mathcal G_h(z;\xi).$$

每步都可由NO先预测新状态，再按同样的缺陷—设置—校正—重建顺序执行。历史$x^n$通过右端保留因果信息；新状态不能脱离历史当作独立稳态场求解。

推进多个时间步时，修正后的$x^{n+1}$成为下一步历史。若观测帧跨度包含多个数值子步，适配器必须使用实际子步关系，并计入整个跨度的时间。显式推进若无需线性求解，则使用其推进关系，不强行引入一个不存在的隐式线性系统。

此前v1/v1.1的NS因果闭合推进是已实现的时域工作点；最新v2快速传递尚未接入该推进器。时域继承证据在实验部分单列。

### 3.5 按算子性质配置内核

| 离散系统性质 | 接入方式 | 数值配置 |
| --- | --- | --- |
| 已消元SPD标量系统 | 当前完整内核直接适用 | 转置限制、Jacobi、Cholesky、能量步长 |
| 非线性且切线SPD | 每次线性化调用相同内核 | 更新残差、Jacobian和样本系统 |
| 隐式时间步SPD空间系统 | 每步调用相同内核 | 质量项、历史右端、时间步长 |
| 多分量SPD系统 | 相同Galerkin/能量关系 | 分量特征；强耦合时用块平滑 |

## 4. 数据一致性与适配器契约

### 4.1 统一输入/输出对象

| 适配器对象 | 数学语义 | 主干用途 |
| --- | --- | --- |
| 网格、自由度、约束 | $\mathcal T_h,E_h,g_h$ | NO输入、图、重建 |
| 残差作用 | $\mathcal R_h(x;\xi)$ | 初始缺陷和更新后的诊断 |
| 线性误差系统 | $A,b$或$Av$ | 当前样本多级作用 |
| 参考算子 | $A^{\rm ref}$ | 可复用层级、图和参考尺度 |
| 局部尺度 | $\operatorname{diag}A$或相容块尺度 | 平滑和残差归一化 |
| 物理/几何特征 | 每自由度向量$q_i$ | 图网络输入 |
| 积分权重 | $W_h$ | 场监督与评价 |
| 重建映射 | $u_h=E_hx+g_h$ | 完整场或新时间步状态 |

当前Darcy适配器提供P1三角单元、正系数与Dirichlet消元。其他PDE提供具有清楚单位、尺度及分量含义的物理通道；特征维数可以扩展，“提升—图消息—门控”的网络结构不依赖方程名称。

### 4.2 同离散目标与误差分离

当前主标签是同一离散系统的高精度解，因此

$$\mathcal R_h(x_h^\star;\xi)\simeq0.$$

连续真解与最终输出的差分为

$$u^\star-u_K=(u^\star-u_h^\star)+(u_h^\star-u_K).$$

第一项是空间/时间离散误差，第二项是当前离散系统内的预测与求解误差。CDMC针对第二项，避免将粗网格上的精确代数解误写成连续真值。

若历史数据标签$x_{\rm data}^\star$由另一离散生成，审计

$$c_h^\star=\mathcal R_h(x_{\rm data}^\star;\xi)$$

即可识别数据—方程失配。此时应先使用相容离散或经过验证的闭合关系。当前自生成Darcy采用同网格、同组装、同右端和同边界，$c_h^\star$仅有数值求解误差，**最新v2主干不需要额外闭合网络**。

### 4.3 由任务特征决定的适配模块

不同任务的额外处理按原因接入，而不是为每个方程重新定义一条主干。

| 任务特征 | 所需适配 | 与统一主干的关系 |
| --- | --- | --- |
| 非规则自由度与边界 | 网格连接、积分权重、自由度映射 | 必要几何接口；后续仍使用代数图与相同多级步骤 |
| 已知非零边界 | 消元右端与精确约束恢复 | 必要约束接口；NO可使用辅助延拓 |
| 多分量耦合或约束 | 块变量、相容投影/块线性化 | 算子性质决定内核；不是附加一个场后处理头 |
| 时间推进或观测帧有较大跨度 | 质量/历史右端或相容子步推进 | 必要时间关系；旧Oseen属于此类推进近似，不是所有PDE共有操作 |
| 真值与部署离散不同 | 一致性审计及经过验证的离散闭合 | 解决数据—算子失配；本页同离散Darcy无需闭合 |
| 输入/方程自由度/输出观测位于不同空间 | 相容输入编码与输出重建映射 | 解决观测空间差异；同节点场无需额外跨模态层 |
| 采用谱基表示几何或粗空间 | 可选谱表示/互补基 | LBO是历史选择；当前v2用图层级和末层代数空间 |

这些适配把物理与任务特征映射到同一状态/缺陷接口。构造相容接口后，连续流程仍是NO提议、一次设置、有限轮校正和场恢复。

## 5. 神经算子提议器

### 5.1 可替换的NO接口

NO一次给出完整场提议：

$$u_0=\mathcal N_\theta(\xi,\mathcal T_h),\qquad
x_0=\operatorname{free}(u_0).$$

边界和已知约束由适配器精确施加。更换适合目标网格的FNO、Geo-FNO、GNO或Transformer骨干，保持这一契约即可；不改变后面的缺陷和数值主干。

当前使用自实现紧凑Geo-FNO风格模型，不是官方论文checkpoint。规则/不规则网格共享架构，已有实验分别训练权重。

### 5.2 当前Geo-FNO内部结构

```text
节点输入→线性提升(24通道)
          │
坐标MLP变形→质量加权非均匀Fourier分析
          │
       32×32潜在格
          │
4个Fourier块：谱混合＋点式混合＋残差＋GELU
          │
Fourier综合回原节点→拼接初始提升特征
          │
   48→64→1节点MLP→尺度恢复→边界施加
```

节点坐标$p_i\in\mathbb R^2$、质量$w_i>0$。Darcy的五维输入为

$$z_i=\left((a_i-7.5)/4.5,\ \gamma_i/0.05,\ p_{i,1},\ p_{i,2},\ \chi_{D,i}\right),$$

线性提升为$h_i=\operatorname{Linear}_{5\to24}(z_i)$。坐标变形MLP为$2\to32\to32\to2$，两隐藏层tanh，末层零初始化：

$$\Phi_\theta(p_i)=p_i+0.15\,d_\theta(p_i).$$

对保留波数$\kappa\in\{-8,\ldots,8\}^2$作质量加权分析：

$$\widehat h_\kappa=\sum_i\frac{w_i}{\sum_jw_j}h_i
\exp\{-2\pi\mathrm i\,\kappa\cdot\Phi_\theta(p_i)\}.$$

系数按FFT归一化乘$32^2$放入潜在格对应频率，经逆FFT并取实部得到$H^{(0)}$。四个块计算

$$H^{(t+1)}=\operatorname{GELU}\!\left[
H^{(t)}+W_t^{\rm local}H^{(t)}
+\mathcal F^{-1}\big(W_t^{\rm spec}(\mathcal F H^{(t)})\big)\right],
\quad t=0,1,2,3.$$

$W_t^{\rm local}$是逐格点通道混合；$W_t^{\rm spec}$在正、负低频带采用可学习复数通道矩阵。块后FFT系数除以$32^2$，截取原保留波数并用共轭相位综合回节点为$\overline h_i$，再预测

$$\delta u_i=\operatorname{MLP}_{48\to64\to1}([\overline h_i,h_i]),$$

$$u_{0,i}=\gamma_i+(1-\chi_{D,i})\,\sigma_u\delta u_i.$$

$\sigma_u$取训练集$|u_h^\star-\gamma_h|$的95百分位尺度，并设下限$10^{-3}$。边界节点$u_{0,i}=\gamma_i=g_i$，自由节点由辅助延拓加网络增量得到，并抽取为$x_0$。冻结后，同网格的Fourier相位、坐标变形和质量归一化可复用；既有执行路径还支持CUDA Graph。此次大网格对照先固定NO初值，在线表另计数值构建与校正。

## 6. 一次NO缺陷驱动的图设置

### 6.1 残差与物理特征

用当前算子计算$r_0=b-Ax_0$，令$d_{0,i}=A_{ii}>0$，归一化为

$$\widehat r_i=\frac{r_{0,i}}{\sqrt{d_{0,i}}},\qquad
\widetilde r_i=\frac{\widehat r_i}
{\max\{\sqrt{N^{-1}\sum_j\widehat r_j^2},\varepsilon_r\}}.$$

当前$\varepsilon_r=10^{-7}$。网络看到残差的空间模式，而不是只看到一个标量范数。

适配器提供五维特征$q_i$。当前Darcy为

$$q_i=\left(
\log a_i/\log12,\quad
\log(d_{0,i}/\operatorname{median}_j d_{0,j}),\quad
p_{i,1},\ p_{i,2},\quad
\log(w_i/\operatorname{median}_j w_j)\right).$$

这些归一化常数属于Darcy数据，不是所有PDE共用的物理量。有符号输入采用相应标准化，不能直接套用正系数的对数通道。

图由参考算子非对角连接形成：

$$G_{ij}=\frac{|A_{ij}^{\rm ref}|}
{\max\{\sum_{j'\ne i}|A_{ij'}^{\rm ref}|,\varepsilon_G\}},
\quad i\ne j,\qquad G_{ii}=0.$$

$G$只用于学习消息；数值作用保留$A$及$R_\ell$的符号。

### 6.2 图神经网络结构

该网络不是Transformer，不直接输出解场、误差场或逆矩阵。结构如下：

```text
[5维物理/几何特征＋1维归一化初始缺陷]
  → Linear(6,32)＋GELU
  → 自身Linear＋邻居聚合Linear＋GELU＋残差
  → 自身Linear＋邻居聚合Linear＋GELU＋残差
  → 输出Linear＋sigmoid
  → 自由度上的有界平滑尺度
```

设节点特征矩阵为$Q\in\mathbb R^{N\times5}$，隐藏表示为$H^{(t)}\in\mathbb R^{N\times32}$；线性权重从右侧作用于各节点行向量，偏置沿节点广播。于是

$$H^{(0)}=\operatorname{GELU}([Q,\widetilde r]W_{\rm in}+b_{\rm in}),$$

$$H^{(t+1)}=H^{(t)}+
\operatorname{GELU}\big(H^{(t)}W_t^{\rm self}
+(GH^{(t)})W_t^{\rm nbr}+b_t\big),\qquad t=0,1.$$

线性输出经sigmoid产生

$$s_{0,i}=0.5+\operatorname{sigmoid}((H^{(2)}W_{\rm out}+b_{\rm out})_i)
\in(0.5,1.5).$$

输出层零初始化，初始门控为1，对应固定MG。历史checkpoint结构有平滑与粗层两个logit；**最新规则多尺度主线只启用平滑门控，粗层门控恒为1**。这样粗层进/出不再额外缩放物理修正。旧不规则pilot仍使用其历史双门控权重，实验中注明。

### 6.3 跨层、跨轮复用

网络只在细层执行一次。门控沿正权重平均传播：

$$s_{\ell+1}=\frac{|R_\ell|s_\ell}{|R_\ell|\mathbf1}.$$

分母仅与网格有关，预先计算。物理缺陷限制使用$R_\ell$，门控平均使用$|R_\ell|$。每一轮重新计算真实$r_k$，但复用初始设置，不重新运行图网络。

NO驱动体现于实际NO初值上的训练、初始缺陷条件化、以及完整校正场监督，不只是多输入一个残差通道。

## 7. 快速网格计划与严格Galerkin层级

### 7.1 参考聚合与平滑插值

适配器定义代表性$A_0^{\rm ref}$；当前Darcy为单位系数、同网格、同边界消元。参考量决定层级、图与尺度，当前样本算子始终来自真实输入。

在每层按强连接形成最多两节点的确定性聚合，节点$i$所属列为$g_\ell(i)$，暂定插值为

$$Q_{\ell,ij}=\begin{cases}1,&j=g_\ell(i),\\0,&\text{其他}.\end{cases}$$

平滑得到

$$P_\ell^{\rm raw}=
\big(I-\omega_\ell^P(D_\ell^{\rm ref})^{-1}A_\ell^{\rm ref}\big)Q_\ell,$$

$$\beta_\ell^{\rm ref}=\max_i
\frac{\sum_j|(A_\ell^{\rm ref})_{ij}|}{(A_\ell^{\rm ref})_{ii}},
\qquad\omega_\ell^P=\min(0.65,1.4/\beta_\ell^{\rm ref}).$$

$D_\ell^{\rm ref}$是参考对角矩阵。未经限制的$P^{\rm raw}$在深层产生大支撑，继而使Galerkin乘法填充增长。

### 7.2 保持原行和的局部支撑

每行保留主聚合列和绝对值最大的其余项，总数最多$m_P$，记保留集合为$S_i$。删除权重的代数和为

$$\delta_i=\sum_{j\notin S_i}(P_\ell^{\rm raw})_{ij}.$$

实际传递定义为

$$P_{\ell,ij}=\begin{cases}
(P_\ell^{\rm raw})_{ij}+\delta_i,&j=g_\ell(i),\\
(P_\ell^{\rm raw})_{ij},&j\in S_i\setminus\{g_\ell(i)\},\\
0,&j\notin S_i.
\end{cases}$$

逐行相加即可得到

$$P_\ell\mathbf1=P_\ell^{\rm raw}\mathbf1.$$

这保留原插值对常数向量的响应，不强制行和为1，允许原有带符号权重。主聚合列缺失时提前为补偿保留一个位置。快速配置$m_P=64$；软件参数0表示无限制对照。

### 7.3 统一参考与当前样本粗空间

限制和参考粗矩阵为

$$R_\ell=P_\ell^\top,\qquad
A_{\ell+1}^{\rm ref}=R_\ell A_\ell^{\rm ref}P_\ell.$$

推荐路径不独立截断粗参考矩阵。当前样本、参考尺度和末层投影全部使用这一套传递。若$A_\ell$ SPD且$P_\ell$满列秩，则

$$v^\top A_{\ell+1}v=(P_\ell v)^\top A_\ell(P_\ell v)>0\quad(v\ne0),$$

因此粗层保持正定。局部化改变粗空间近似能力；行和补偿本身不能替代满列秩条件，具体配置通过数值检查和末层Cholesky验证。

计划保存单元几何、自由/固定节点、参考层级、传递、消息图、参考尺度和末层投影。相同网格及参考配置供多系数/源项查询复用。改变自由度、约束或参考设置时重建；本轮计时衡量真实新网格构建，不用缓存命中冒充冷构建。

## 8. 当前样本的矩阵无关多级系统

### 8.1 细层算子、右端与对角线

有限元算子由单元贡献组成。令$C_t$抽取单元$t$的局部节点，$K_t(\xi)$为局部矩阵，$E_h$为自由度注入，则

$$A_0(\xi)=E_h^\top\left(\sum_t C_t^\top K_t(\xi)C_t\right)E_h.$$

作用于向量$v$时，按“自由度注入—单元抽取—局部作用—节点累加—自由度抽取”执行：

$$A_0v=E_h^\top\sum_t C_t^\top\big[K_t(\xi)(C_tE_hv)\big].$$

局部小矩阵和几何量可直接计算，无需逐样本创建完整稀疏刚度矩阵。右端仍为第3节的载荷减边界贡献；当前细层对角线按单元对角贡献累加，保持精确。**矩阵无关改变执行表示，不改变离散方程。**

这一接口不限定单元形状。有限体积可实现面通量作用，有限差分可实现模板作用；它们仍须提供相容右端、对角尺度及约束。

### 8.2 因子化Galerkin作用

定义从第$\ell$层到细层的传递链

$$V_0=I,\qquad V_\ell=P_0P_1\cdots P_{\ell-1}.$$

于是当前样本每层算子为

$$A_\ell(\xi)=V_\ell^\top A_0(\xi)V_\ell.$$

实际施加$A_\ell v$分三步：

1. 从第$\ell$层顺次延拓至细层，得到$v_0=V_\ell v$。
2. 调用当前样本的细层作用，得到$w_0=A_0(\xi)v_0$。
3. 从细层顺次限制回第$\ell$层，得到$w_\ell=V_\ell^\top w_0$。

因此主干使用的是当前样本的**严格Galerkin作用**，并非用参考算子代替真实物理。参考粗矩阵只服务于一次性计划和尺度；在线不重新进行全部中间层稀疏矩阵乘法。

### 8.3 中间层的参考校准对角尺度

精确算子作用与平滑对角尺度是两个不同对象。当前细层用精确$d_0=\operatorname{diag}A_0$；非末层的粗层用参考校准尺度，省去逐样本精确粗对角线构造。

记$d_\ell^{\rm ref}=\operatorname{diag}A_\ell^{\rm ref}$，$S_\ell=(P_\ell\odot P_\ell)^\top$，其中$\odot$为逐项乘法。令$\widetilde d_0=d_0$，逐层计算

$$\widetilde d_{\ell+1}=d_{\ell+1}^{\rm ref}\odot
\frac{S_\ell\widetilde d_\ell}{S_\ell d_\ell^{\rm ref}},
\qquad \ell=0,\ldots,L-2.$$

除法逐节点执行；实现对分母设数值下限。平方权重传递给出局部尺度变化，参考粗对角补回参考问题中的完整耦合。当$A_0=cA_0^{\rm ref}$且$c>0$时，递推给出$\widetilde d_\ell=cd_\ell^{\rm ref}$，与真实粗对角相同。一般非均匀系数下，这是**平滑尺度近似**，不是精确粗对角。

网络门控$s_\ell$与这一尺度共同设置平滑强度。当前样本的残差计算、Galerkin作用和外层能量计算仍精确使用$A_0(\xi)$；末层则直接解精确投影的小系统。

### 8.4 当前样本末层直接求解

末层维数为$q=N_L$，当前配置以128为粗化停止目标，本页测试末层均满足$q\le128$；一般网格还需检查粗化进展与层数上限。末层基为$V_L$，投影矩阵为

$$A_L(\xi)=V_L^\top A_0(\xi)V_L
=\sum_t(C_tE_hV_L)^\top K_t(\xi)(C_tE_hV_L).$$

网格计划预先保存末层基的单元投影几何。每个新样本只更新其物理系数，计算$q\times q$局部Gram累加，数值对称化后作

$$A_L=\mathsf L_L\mathsf L_L^\top.$$

末层调用解$A_Ly_L=f_L$：先解$\mathsf L_Lz=f_L$，再解$\mathsf L_L^\top y_L=z$。这是Cholesky分解和两次三角求解，不显式形成$A_L^{-1}$。同一样本的两轮V-cycle共用该分解；当前配置不构建未使用的参考逆，也不在末层调用PCG。

末层只有一个累计投影基；不为每个中间层保存完整的稠密累计基。中间层保留局部稀疏传递和因子化作用。

## 9. 完整V-cycle、能量更新与场恢复

### 9.1 多尺度误差处理的物理意义

细层平滑处理在邻近自由度间变化快的误差；粗层表示在细层平滑后仍然存在的、跨较大区域变化缓慢的误差。对一般图，“高频/低频”应理解为**相对于当前离散算子的代数振荡/代数平滑**，而不要求网格具有规则Fourier频率。

局部消息网络改变有限次平滑的空间分配；限制和延拓传播远距离信息；末层小系统共同求解全域的低维误差。这三者分工使局部网络无需单独学习完整的全局逆。

### 9.2 单轮V-cycle逐步定义

外层第$k$轮首先得到细层缺陷$r_k=b-A_0x_k$。本轮解的是误差子问题，内部修正初值为零，与当前状态$x_k$不同。设进入层$\ell$的内部右端为$f_\ell$，细层$f_0=r_k$。

```text
细层 f0=rk，内部修正从0开始
   2次预平滑 → 剩余缺陷 → 限制
      下一层：2次预平滑 → 剩余缺陷 → 限制
                     ⋮
              末层当前样本Cholesky解
                     ⋮
      延拓粗修正 → 加到当前层 → 2次后平滑
   延拓粗修正 → 加到细层 → 2次后平滑
返回细层修正方向 dk
```

对非末层，令$y_\ell^{(0)}=0$，定义

$$D_\ell^\theta=\operatorname{diag}\left(
\omega_\ell s_\ell\oslash\widetilde d_\ell\right),
\qquad \omega_\ell=\min(0.67,1.6/\beta_\ell^{\rm ref}),$$

其中$\oslash$为逐项除法。先做$\nu=2$次预平滑：

$$y_\ell^{(j+1)}=y_\ell^{(j)}+
D_\ell^\theta\big(f_\ell-A_\ell y_\ell^{(j)}\big),
\qquad j=0,1.$$

计算剩余缺陷并限制：

$$\rho_\ell=f_\ell-A_\ell y_\ell^{(2)},\qquad
f_{\ell+1}=P_\ell^\top\rho_\ell.$$

递归求得下一层修正$y_{\ell+1}$，延拓叠加：

$$\overline y_\ell=y_\ell^{(2)}+P_\ell y_{\ell+1}.$$

以$\overline y_\ell$为起点再做两次相同形式的后平滑。末层直接求$y_L=A_L^{-1}f_L$；返回细层所得$d_k=y_0$。上述主线的粗层门控为1，因此限制/延拓均不附加学习缩放。

这一数值过程记作

$$d_k=B_\psi(A_0;\mathcal T_h,r_0)r_k.$$

给定样本、初始设置和层级后，V-cycle对输入$r_k$是线性作用；整个预测器因NO、图设置和步长而非线性。$B_\psi$是内部多级近似逆作用，不是网络直接输出的一张逆矩阵。

### 9.3 真实细层能量上的标量更新

对SPD线性系统，定义离散能量

$$\mathcal E(x)=\frac12x^\top A_0x-b^\top x.$$

沿$d_k$更新$x_k+\alpha d_k$。将二次项展开，利用$A_0$对称及$r_k=b-A_0x_k$，得到

$$\mathcal E(x_k+\alpha d_k)-\mathcal E(x_k)
=-\alpha r_k^\top d_k+\frac{\alpha^2}{2}d_k^\top A_0d_k.$$

对$\alpha$求导为$-r_k^\top d_k+\alpha d_k^\top A_0d_k$。无约束最小值位于

$$\alpha_k^{\star}=\frac{r_k^\top d_k}{d_k^\top A_0d_k}.$$

当前采用区间$[0,2]$内的最小值：

$$\alpha_k=\operatorname{clip}_{[0,2]}(\alpha_k^{\star}),
\qquad x_{k+1}=x_k+\alpha_kd_k.$$

实现将分母下限设为$10^{-12}$，处理极小方向。这里只有一次真实$A_0d_k$和标量内积，没有多候选线搜索，没有接受阈值驱动的加轮。

由于区间包含0，精确算术下此更新不增加二次能量。进一步由$A_0x_h^\star=b$可得

$$\mathcal E(x)-\mathcal E(x_h^\star)
=\frac12(x-x_h^\star)^\top A_0(x-x_h^\star).$$

因此能量下降对应$A_0$范数误差下降。评价关注的质量加权场误差属于另一个范数；训练直接监督该场误差，补足能量准则与部署指标之间的差别。初始设置固定后，当前法是少步缺陷修正/预条件梯度型更新，而不是PCG。

### 9.4 固定两轮与最终输出

完整在线流程为：

1. NO预测并精确施加约束，得到$x_0$。
2. 构造当前样本作用、右端、尺度及末层分解；计算$r_0$。
3. 图网络运行一次，门控限制到全部层。
4. 对$k=0,1$，重新计算$r_k$，执行完整V-cycle得到$d_k$，计算真实能量步长并更新$x_{k+1}$。
5. 输出$u_K=E_hx_K+g_h$，恢复原网格节点顺序和边界。

非线性接入时，本次输出是增量$\delta_K$，由适配器更新状态$z+\delta_K$；时域接入时，输出新时间步状态并写入历史。它们的外层推进和物理稳定化属于第3节的接入模块，不修改V-cycle内部的符号含义。

## 11. Darcy适配器：一般接口的具体实例

### 11.1 从守恒方程到P1系统

介质系数$a(\mathbf p)>0$，通量$\mathbf j=-a\nabla u$。局部守恒$\nabla\cdot\mathbf j=f$给出

$$-\nabla\cdot(a\nabla u)=f\quad\text{于}\ \Omega,
\qquad u=g\quad\text{于}\ \partial\Omega.$$

对边界上为零的测试函数$v$，乘积积分并分部积分：

$$-\int_\Omega v\nabla\cdot(a\nabla u)\,\mathrm d\mathbf p
=\int_\Omega a\nabla u\cdot\nabla v\,\mathrm d\mathbf p
-\int_{\partial\Omega}v\,a\nabla u\cdot\mathbf n\,\mathrm ds.$$

边界项因$v=0$消失，弱形式为

$$\int_\Omega a\nabla u\cdot\nabla v\,\mathrm d\mathbf p
=\int_\Omega fv\,\mathrm d\mathbf p.$$

P1线性基函数在每个三角形上梯度恒定。单元$t$采用顶点系数均值$\overline a_t$，得到

$$K^t_{ij}=|t|\overline a_t\nabla\phi_i\cdot\nabla\phi_j,
\qquad f^t_i=|t|/3\quad(f=1).$$

按共享节点相加得到全局关系，再按第3.1节消元。正系数、相容网格和充分Dirichlet约束使自由度系统SPD。规则域和凹口域**均采用这一P1定义**，不是规则域一套差分、不规则域另一套残差。

### 11.2 单元形式的精确末层投影

对末层基第$j$列，预计算每个单元上的两个梯度分量

$$G_{t,j}^{x}=\partial_x(V_L)_j|_t,
\qquad G_{t,j}^{y}=\partial_y(V_L)_j|_t.$$

当前样本令$w_t=|t|\overline a_t$，末层矩阵直接为

$$A_L=(G^x)^\top\operatorname{diag}(w)G^x
+(G^y)^\top\operatorname{diag}(w)G^y.$$

每个查询仅变$w$，同网格$G^x,G^y$复用。这个公式是$V_L^\top A_0V_L$的单元展开，避免逐样本构造所有中间层矩阵。

### 11.3 数据、边界与几何

| 要素 | 当前v2定义 |
| --- | --- |
| 方程/源项 | 稳态标量Darcy，$f=1$ |
| 系数 | 母Gaussian随机场经零阈值取3/12，对比度4:1 |
| 规则几何 | 单位方形，规则节点排布，每个方格两个三角形 |
| 不规则几何 | 顶部矩形凹口的约束三角剖分 |
| 边界 | 相容Dirichlet；当前多尺度主表为零边界 |
| 网格输入 | 节点坐标、三角形连接、边界掩码、集总质量 |
| 主真值 | 同网格、同系数均值规则、同载荷和边界的高精度稀疏直接解 |
| 场误差权重 | $m_i=\sum_{t\ni i}|t|/3$ |

数据格式统一为mesh、train/val/test和manifest；具体规范见[Darcy v2生成规范](../../../../baselines/data/darcy_v2/SPEC.md)。它是同离散可审计数据，不是官方FNO/NORM测试集的复制。

当前v2的几何适配直接使用网格与代数图，不需要LBO特征分解、额外固定谱扩散或跨模态输出头。LBO是v1部分实验的历史表示，不是一般PDE多级主干的必选部件。若任务输入、方程自由度和输出观测不在同一空间，适配器再提供相容映射；同网格Darcy不需要该分支。

### 12.1 指标、基线和对照条件

本节最新结果均来自已有JSON，本次整理没有新增训练或推理实验。当前v2场指标定义为

$$\operatorname{Rel}_{W}(u,u_h^\star)=100\times
\sqrt{\frac{(u-u_h^\star)^\top W_h(u-u_h^\star)}
{(u_h^\star)^\top W_hu_h^\star}}.$$

表内场误差单位为**百分比**；mean是逐样本相对误差的平均，不是先平均场再计算误差；P95是逐样本误差的95百分位。下降比例为$100(1-e_{\rm new}/e_{\rm base})$，而两个百分比误差相减的单位是“百分点”。

| 基线 | 初值、学习与数值作用 |
| --- | --- |
| NO | 同一冻结神经算子，直接输出，K=0 |
| 零初值固定MG | 自由度从0开始，边界按原样本保留；所有门控为1 |
| NO+固定MG | 使用与CDMC相同NO初值、相同层级、末层解法与轮数；所有门控为1 |

| FEM直接解 | 同网格P1组装、边界消元与成熟SciPy稀疏直接解；用于核对真值和CPU成本 |

## 13. 计算成本、复杂度与已有优化

### 13.1 一次性成本和每次查询成本

设同一网格查询$Q$次，统一计时写成

$$T_{\rm total}(Q)=T_{\rm mesh}+T_{\rm NO,prepare}
+\sum_{s=1}^{Q}\left(T_{\rm input}^{(s)}+T_{\rm NO}^{(s)}
+T_{\rm system}^{(s)}+T_{\rm correct}^{(s)}+T_{\rm output}^{(s)}\right).$$

| 时间项 | 所在流程 | 计算内容 |
| --- | --- | --- |
| $T_{\rm mesh}$ | 新网格一次 | 几何、参考算子、层级、图、参考尺度、末层投影 |
| $T_{\rm NO,prepare}$ | 冻结NO/固定网格一次 | 坐标变形、相位、质量归一化及可选图捕获 |
| $T_{\rm input}$ | 每样本 | 系数/边界输入转换、必要设备搬运 |
| $T_{\rm NO}$ | 每样本 | 神经算子初始场预测 |
| $T_{\rm system}$ | 每样本、校正前 | 单元系数、精确细层对角/右端、中间尺度、末层Gram和Cholesky |
| $T_{\rm correct}$ | 每样本 | 一次图设置、门控传播、两轮完整V-cycle和能量更新 |
| $T_{\rm output}$ | 每样本 | 自由度和约束恢复；按应用要求输出 |

第12.2节只实测最新$T_{\rm mesh}$及$T_{\rm system}+T_{\rm correct}$。旧的小网格CUDA Graph端到端计时另有NO/输入；这两种范围以字段区分。

### 13.3 与数学流程对应的复杂度

令$N=N_0$，单元/面数量为$T$，细层一次算子作用成本为$C_0$，传递总非零数为$S_P=\sum_{\ell=0}^{L-1}\operatorname{nnz}(P_\ell)$，图边数为$E_G$，网络宽度为$c$。

局部传递给出

$$S_P\le m_P\sum_{\ell=0}^{L-1}N_\ell.$$

当层规模近似几何递减时，$\sum_\ell N_\ell=O(N)$，因此传递存储及一次完整传递链为$O(m_PN)$。这约束传递，不直接保证所有参考粗矩阵的行度有界；冷构建中的稀疏矩阵乘法仍依赖实际填充。

| 对象/计算 | 量级 | 当前取值或执行方式 |
| --- | --- | --- |
| 细层单元作用 | $O(T)$，即$C_0$ | 小局部作用与scatter；P1二维通常$T=O(N)$ |
| 一次图设置 | $O(E_Gc+Nc^2)$ | 固定两消息层，$c=32$；每样本一次 |
| 门控跨层传播 | $O(S_P)$ | 每样本一次，供两轮复用 |
| 第$\ell$层隐式作用 | $O(C_0+\sum_{j<\ell}\operatorname{nnz}P_j)$ | 每次都延拓到细层再限制 |
| K轮完整数值校正 | $O(K(\nu+1)L(C_0+S_P)+Kq^2)$ | $K=2$、每侧$\nu=2$；含各层多次作用及末层三角解 |
| 末层投影几何存储 | $O(Tq)$ | 两个梯度阵；$q\le128$ |
| 当前样本末层Gram | $O(Tq^2)$ | GPU加权矩阵乘法；每样本一次 |
| 末层分解/每次解 | $O(q^3)$ / $O(q^2)$ | 小矩阵Cholesky；分解跨两轮复用 |

固定$m_P,q,K,\nu$且$L=O(\log N)$时，当前因子化校正的保守量级为$O(N\log N)$；这里的$\log N$来自各层反复返回细层。显式、稀疏度受控的理想MG可达到近线性量级。因此当前优势是**任务匹配带来的少轮场精度和减少重复装配**，而不是低于最优MG的普适复杂度。

三角网格局部算子以及神经设置可并行；粗层因果递归仍存在。NO对目标全局结构的预测可降低所需校正预算，学习设置进一步改善同预算误差，这是CDMC将网络能力转化为总体收益的位置。

### 13.4 已整合的优化及其方法含义

| 改进 | 减少的工作 | 保持不变的对象 |
| --- | --- | --- |

## 14. 核心机制、统一性与研究命题

### 14.1 NO与数值作用的互补关系

定义NO遗留误差$e_0=x_h^\star-x_0$。给定样本和一次设置，第$k$轮有$r_k=A_0e_k$，于是

$$e_{k+1}=e_k-\alpha_kB_\psi r_k
=(I-\alpha_kB_\psi A_0)e_k,$$

$$r_{k+1}=(I-\alpha_kA_0B_\psi)r_k.$$

最终误差因而是

$$e_K=(I-\alpha_{K-1}B_\psi A_0)\cdots
(I-\alpha_0B_\psi A_0)e_0.$$

通用多级求解器追求广泛误差方向上的收缩；CDMC利用已有NO，使学习重点落在**实际$e_0$分布及其有限轮传播**。最终场监督优化组合，而不要求小型网络学会所有方向的精确逆。这是将NO和数值主干连接的中心机制。

该关系同时解释三个工作点：K=0为NO；门控全部为1是NO后固定MG；学习门控是NO驱动的互补多级后求解。零初值固定MG提供纯数值工作点。它们在同一离散目标和可审计预算下形成精度—成本曲线，而非分别比较不对齐的残差与场标签。

### 14.2 统一到什么层次

| 层次 | 跨PDE保持的定义 | 变化内容 |
| --- | --- | --- |
| 问题接口 | 状态、残差、约束、重建 | 连续物理与空间/时间离散 |
| NO提议 | 完整离散状态初值 | 输入通道、适合网格的骨干、训练权重 |
| 学习设置 | 物理/几何/初始缺陷→小型图设置 | 特征尺度，必要的分量/块扩展 |
| 多级作用 | 聚合、传递、粗投影、平滑、末层解 | 算子性质决定稳定的具体内核 |
| 预算与输出 | 固定少轮校正、自由度恢复 | 非线性外更新、时间因果推进或观测映射 |

当前规则/不规则Darcy共享同一适配器定义和SPD数值内核；一般SPD问题可复用主干并提供自己的离散作用。非线性/时域的统一来自“形成误差子问题—调用内核—更新物理状态”的组合，不来自抹去质量矩阵、历史和切线。非对称/鞍点系统保留上层流程，配置相容数值内核后接入。
