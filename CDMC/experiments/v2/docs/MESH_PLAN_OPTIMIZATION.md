# CDMC v2：多级网格计划的扩展性优化

日期：2026-09-28。本文承接[原始扩展性审计](MESH_PLAN_SCALING_AUDIT.md)，记录最终接入前的探针与设计取舍。相同算法现已接入正式 v2 的 evaluate-compiled 命令；正式入口复测见[阶段整理](CURRENT_STAGE.md)，后续大网格完整求解与 FEM 对比见[大网格对比](LARGE_MESH_COMPARISON.md)。原 evaluate 后端仍保留为对照。

## 原因

原始矩阵无关 CDMC 在每个新网格上生成稠密累计投影基 $Q_0=I,\;Q_{\ell+1}=Q_\ell P_\ell$，然后逐单元编译“系数到所有粗层对角线及最底层矩阵”的映射。6.6 万节点时，单个稠密 $Q_0$ 需要约 15.75 GiB GPU 空间；4225 节点时，完整构建 90 秒内未完成。

简单地将 $Q_\ell$ 改成 CSR 并未完全解决问题：中间层累计投影的非零项会扩散。在 16,641 节点的层级中，其非零项从第 1 层约 6.4 万增长到第 5 层约 **810 万**，精确对角线映射编译仍在 60 秒内未完成。另一个重复成本是原网格计划已经建立参考 Galerkin 层级，后续又用单位系数重新组装一遍参考系统。

## 保留多级 CDMC 的改法

层级作用保持 Galerkin 定义，但在线只沿稀疏传递链施加矩阵：

$$
A_\ell(a)v
=R_{\ell-1}\cdots R_0\,A_0(a)\,P_0\cdots P_{\ell-1}v.
$$

$A_0(a)$ 是当前系数的精确 P1 单元作用。构建时不存储累计 $Q_\ell$。中间层 Jacobi 对角线使用参考层级和当前细层对角线给出尺度：

$$
\widetilde d_0(a)=\operatorname{diag}A_0(a),\qquad
\widetilde d_{\ell+1}(a)
=d_{\ell+1}^{\mathrm{ref}}\odot
\frac{(P_\ell\odot P_\ell)^\top\widetilde d_\ell(a)}
     {(P_\ell\odot P_\ell)^\top d_\ell^{\mathrm{ref}}}.
$$

分式逐点计算；$P_\ell\odot P_\ell$ 为逐元素平方。此式对统一系数倍乘是精确的，对异质系数是近似。最底层仍用上述**当前样本的精确 $A_L(a)$ 作用**执行固定两步 PCG，不预编译末层矩阵；完整求解的残差和能量步长继续用精确 $A_0(a)$。参考层级在首次构建后直接留下，用于 $d_\ell^{\mathrm{ref}}$、阻尼及末层参考逆，省去第二次参考系统组装。NO 权重、CDMC 图网络权重和两轮 V-cycle 均未重训或更换。

曾测试更便宜的末层参考矩阵缩放：规则 Darcy 平均误差升到 **0.04184%**，原版为 **0.01020%**。因此末层的当前系数作用必须保留；该失败分支仅存档，不作为推荐路径。

## 构建时间

以下为**同一个最终构建模式** `implicit-terminal-full` 的单次结果，服务器 gtmsmw、RTX 4090、规则 P1 三角网格。只构建计划，不训练模型，也不测大网格推理；GPU 进程内存限制为设备容量的 15%。由于是单次墙钟，千节点两行顺序不代表稳定的规模规律。

| 网格 | 节点 / 三角形 | 构建时间 | 峰值 PyTorch GPU allocated | 峰值进程 RSS |
| --- | ---: | ---: | ---: | ---: |
| 33×33 | 1,089 / 2,048 | 0.827 s | 2.7 MiB | 706 MiB |
| 65×65 | 4,225 / 8,192 | 0.624 s | 14.0 MiB | 715 MiB |
| 129×129 | 16,641 / 32,768 | 4.142 s | 72.8 MiB | 778 MiB |
| 257×257 | 66,049 / 131,072 | **46.537 s** | **427 MiB** | **1,148 MiB** |

作为过程对照，稀疏精确投影映射在 4225 节点上需 **3.73 秒**，在 16,641 节点上超过 **60 秒**。保留精确末层矩阵、只近似中间层对角线的版本在 16,641 节点上需 **19.83 秒**，在 66,049 节点上超过 **180 秒**。最终实现把后一规模的完整构建变成了 46.537 秒。当前冷启动大头已转为参考层级的 CPU 构造；它仍随规模明显增长。

## 已有权重的求解核对

同一 Darcy pilot 权重，每组 16 个测试样本，热态单样本端到端时间含 CPU 输入、NO 和两轮 CDMC。旧版数值取现行正式评测；新结果在另一轮同型号 GPU 上测得，时间比值只作量级参考。误差是质量加权相对场 $L^2$ 百分比。

| 测试 | 旧 CDMC 误差 / ms | 新路径误差 / ms | 新路径 P95 误差 |
| --- | ---: | ---: | ---: |
| 规则 Darcy | 0.01020% / 4.253 | **0.01028% / 2.169** | 0.01595% |
| 不规则 ID | 0.00899% / 4.229 | **0.00822% / 2.163** | 0.01479% |
| 几何 OOD | 0.05711% / 4.188 | **0.05131% / 2.058** | 0.09150% |

本测试验证了小网格已训练模型的预测质量以及最终方案的 CUDA 图执行。**6.6 万节点只验证了构建时间与内存**；尚无该尺度上的 NO/CDMC 推理精度和热态时间，也未测试工业级不规则拓扑或其他 PDE。46.5 秒冷启动适合固定网格反复求解的场景；若每个样本都换网格，它仍可能抵消热态提速。
