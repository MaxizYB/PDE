# 自主研究的轻量记录模板

与 [RESEARCH_PROTOCOL.md](RESEARCH_PROTOCOL.md) 配套。按实际需要复制到研究项目已有文档，不必一次创建所有文件；同一个信息不重复维护。以下空项是模板，不是已完成的研究结果。

快速阶段：每个配置一次训练、固定开发 seed；最终候选冻结后才做多 seed。模板用于帮助研究判断，不是增加审批手续。

## 1. 项目状态与恢复入口

复制到项目 README，始终只列一个当前候选。

~~~markdown
# <项目名称>

更新日期：<YYYY-MM-DD>。阶段：<A/B/C/D/E/F>。

科学目标：<问题与成功后的价值，一句话>。
当前候选：<方法版本、源码标识、方法文档链接>。
当前结论：<最重要的已证实认识；证据 run_id>。
主要未知：<当前阻碍研究成立的最大问题>。
下一步：<一项能区分解释或推进中心主张的动作>。

| 对象 | 状态 | 证据或运行位置 | 下一动作 |
| --- | --- | --- | --- |
| <方法/任务> | <已完成/运行/暂停/待做> | <链接、run_id/作业标识> | <动作> |

文档入口：<立论>、<文献>、<完整方法>、<证据总账>、<决策日志>。
数据/权重位置：<服务器相对路径，不含连接凭据>。
已有任务与恢复命令：<无则明确写无；只写经核实可用的命令>。
~~~

## 2. 问题立论卡

复制到 QUESTION，随认识变化更新；修订原因追加到 LOG。

~~~markdown
# 研究立论

## 科学需求与后果
<谁需要解决什么；当前失败改变了哪个科学/物理结果。>

## 研究对象与可观测现象
<输入、输出、条件、失败的操作性定义与可信参考。>

## 现有路径与具体缺口
<最直接前作及其实际能力；客观事实和我们的推断分开。>

## 中心机制与可证伪预测
<共同障碍是什么；机制若成立/不成立应分别观察到什么。>

## 成功标准与价值来源
<主指标、通用指标、具有意义的效果尺度、完整成本范围及其依据。>
<不仅说明方法会更好，也说明因此新增了什么认识或能力。>

## 一般性与检验轴
<哪些变化仍共享该机制；选择哪些代表性变化可以检验它。>

## 当前最大反证风险
<若简单替代已经足够、现象由数据处理造成等，将如何识别。>
~~~

## 3. 文献核查与重叠审计

每篇关键论文使用同一条目，放入 LITERATURE；不要为每篇新建文件。

~~~markdown
### <文献编号：标题>

- 书目：<作者、年份、期刊/预印本、DOI、版本、公开链接>。
- 读取范围：<正文章节、公式/图/表、补充材料、代码版本；未获取部分>。
- 客观方法：<问题、输入输出、关键表示、学习目标、数值与网络流程>。
- 实验事实：<数据、参考、主要对照、原始指标、成本、泛化设置及定位>。
- 作者明确限制：<原文位置与准确释义；没有报告则写未报告>。
- 我们的解释：<推断出的缺口、条件与尚待验证部分，不当作作者结论>。
- 与我们重叠：<去掉名称后相同的公式、计算、训练和能力>。
- 实质差异：<拟新增的机制/表示/能力；用哪项实验区分>。
- 核查日期：<YYYY-MM-DD>。
~~~

定期在文献表后汇总一张对照表：研究目标、部署可用信息、核心计算、训练监督、在线代价、已验证能力、共同部分、实质差异。比较对象以最接近工作为主，不只挑老旧或无关方法。

## 4. 一轮开发实验卡

运行前写入 LOG；结束后在同条目追加结果，原先预测保留。

~~~markdown
### <日期 / experiment_id / 所处阶段>

假设：<本轮唯一主要待决问题>。
竞争解释：<至少最值得排查的另一种原因>。
已有证据：<为什么本轮值得做；哪些结果无需重跑>。
本轮修改：<改变什么及共同机制；保持什么不变>。

协议：<数据与划分、基底/权重、参考、训练量、开发 seed>。
主指标与科学尺度：<定义、方向、具有意义的变化及依据>。
辅助指标：<用于避免错误解释的最少必要量>。
判断：支持时<观察>；反驳时<观察>；无法区分时<观察>。
运行：<真实命令、配置、run_id、输出路径>。
重复规则：单次；如需异常复测，记录具体异常、原 run_id 和理由。

运行后追加：
有效性：<有效/无效及原因>。
结果：<原始数值、配对差异、主要切片与完整成本；链接>。
解释：<支持/反驳/未决；证据实际回答了什么>。
最大障碍：<当前最重要而不是最容易优化的障碍>。
决定：<继续/改变方法/回机制/回调研/候选冻结>。
下一步：<一项行动与预期新增信息；不预排大量相似实验>。
~~~

## 5. 运行清单与结构化输出

以下为有效 JSON 的空模板，可作为 manifest.json 起点。stage 使用 development 或 final；interpretation 与 lifecycle 分开。仅填写真实信息，未执行的条目保留 null，不补造运行标识。

  "interpretation": null,
  "method": {"name": null, "revision": null},
  "command": null,

~~~

正式结果的最小输出：

| 文件 | 内容 |
| --- | --- |
| manifest.json / resolved_config | 可追溯输入、版本、实际参数和运行状态 |
| train.log / evaluate.log | 实际日志，按运行内容保留，不要求无训练任务产生训练日志 |
| metrics.json | 全部指标、单位、定义版本、统计量、成本范围与样本数 |
| per_sample.csv | 独立实例 ID、方法、配置、各指标及必要物理条件 |
| summary.csv / summary.md | 自动生成的主表；原始误差、改善比例、时间、内存及条件 |
| source_data / figure outputs | 使用到的图表源数据及绘图配置/命令；需要绘图时产生 |

可使用项目已有等价文件，不要求机械改名。开发训练与最终评测可分 run_id，通过权重哈希及父运行关联。

## 6. 决策日志与主张总账

LOG 追加条目不必重抄实验卡，只保留能恢复判断的内容：

~~~markdown
### <时间 / decision_id>

依据：<run_id、理论或文献位置>。
新事实：<实测事实>。
研究解释：<对机制的影响；与事实区分>。
当前主要障碍：<一项>。
决定及原因：<选什么、放弃什么、为什么>。
返回节点：<A/B/C/D/E/F>。
同步更新：<METHOD / QUESTION / EVIDENCE / 稿件位置>。
下一步与恢复：<任务、状态、命令或路径>。
~~~

EVIDENCE 中按主张维护下表，行数随中心论证而定：

| ID | 科学主张 | 预定判据 | 核心证据/对照 | 反例与替代解释 | 效应与成本 | 状态 | 稿件位置 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| <C1> | <具体、可检验> | <成功意味什么> | <run_id/公式/文献> | <已处理/待决> | <原始数值> | <开发支持/独立确认/被反证/待验证> | <节/图> |

主表至少同时给出基底、最强相关替代和当前完整方法。核心消融每一行对应一个解释，表下说明证据如何支持该解释，不把所有小改动列成无主次的清单。

## 7. 候选冻结与准出检查

快速开发不要提前填写成已通过。只有形成候选后使用此表，最终 seed 数量和实验范围在看结果前确定。

~~~markdown
## 候选冻结

- 候选方法、源码/权重哈希：<填写>。
- 核心主张与有效效果尺度：<链接 QUESTION/EVIDENCE>。
- 冻结的数据、划分、指标、基线和选模规则：<配置链接>。
- 最接近前作最新核查：<日期和差异证据>。
- 最终多 seed 计划：<覆盖哪个训练环节、选择的数量及理由>。
- 独立测试/物理变化：<选择理由及此前使用情况>。
- 正式时间/内存协议：<硬件、场景、重复安排和成本边界>。
- 准出判断规则：<达到什么状态通过；失效时回到哪个环节>。

## 整体审核

- [ ] 问题的科学价值和共同机制明确。
- [ ] 与最接近前作的实质差异经原文核查和实验支持。
- [ ] 参考解、算子、标签、物理读出与指标对齐。
- [ ] 最强相关对照有效，共享信息、资源和比较条件清楚。
- [ ] 中心机制、主要反例与核心消融形成完整解释。
- [ ] 最终独立验证及多 seed 支撑所声明的稳定性。
- [ ] 冷热成本、训练投入、单样本/批量和计时范围明确。
- [ ] 方法从输入到输出完整，源码和文档一致。
- [ ] 每项主张、每个图表和摘要数字均有可追溯来源。
- [ ] 关键复现已按保存的命令、配置和环境核查。
- [ ] 数据/代码/源数据及许可、实质 AI 辅助记录齐全。
- [ ] 人类研究者已复核核心科学判断与投稿材料。

未通过项：<问题、返回节点、最关键下一步>。
最终建议：<继续研究/进入整合/具备投稿准备>。
~~~

## 8. 持续稿件的最小骨架

可以直接使用期刊模板；此骨架只规定论证内容，不固定图数和篇幅。

~~~markdown
# <围绕中心进展的标题>

## Abstract
<重要问题—关键洞见—方法—核心实证—科学意义。>

## Introduction
<需求与物理后果—现有研究路径—具体缺口—本文贡献。>

## Results
<按实际科学论证分节：现象、机制、方法能力、科学后果与迁移。>
<每小节关联主张 ID、图表源数据和独立证据。>

## Discussion
<新增认识、实际价值、条件规律、未解问题及后续科学方向。>

## Methods
<符号与假设—数学/物理推导—完整预测流程—模型内部结构。>
<数据与参考—训练与选模—基线—指标—计时—统计—复现。>

## Data availability / Code availability / AI assistance
<对应目标期刊要求；真实描述取得材料和辅助研究的方式。>

## Supplementary information
<支撑性推导、完整配置、额外验证和次要结果。>
~~~

用文字清晰陈述尚待验证的预期，只有完成的实验进入实证结论；不要预填看起来像真实结果的示例数字。
